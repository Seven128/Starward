### `miniapp-map-discovery`

- Primary question: Which formal stargazing spot should I find, evaluate and act on without losing the map or current observing context?
- Main surface owns: the one physical map; one fixed floating Search entry; the dedicated `spot/search` child; the one formal-spot selection; the three-extent `map-spot-information-panel`; and the current layer/time, route, favorite, contribution and evidence actions. The Map Search entry contains only Search affordance and current query summary when applicable. Search owns one visual field shared with the entry, anchored query suggestions, a titleless wrap-safe immediately committed multi-select filter group and `想去`/`其他观星点` result partitions. Its visible/system/edge Back paths return to Map through one reversible child transition; neither field state carries a trailing clear/close action. Filter choices use a semantic prefix icon plus stable text and a non-layout overlapping selected ornament. Partition disclosure retains item identity, focus, scroll anchor and live geometry without flicker. Whole result cards commit selection and return to Map; there is no trailing selection button, and media cards retain a faint image beneath a fixed half-width leading readability field.
  Search activation preserves the field and its rendered query/placeholder as a stationary visual anchor while child content reveals below it; compact suggestions and a titleless filter group follow without oversized vertical gaps. A marker or returned result opens the same panel at `medium`. The three visible extents retain one continuous objective document and differ only by viewport clipping; `large` alone enables its vertical scroll, and valid media is the sole presentation exception, pulled into the document top during medium-to-large progress. Without media, a compact handle band remains; with media, the handle overlays the image and the band consumes no height. Only the small rectangular handle hit region may manipulate extent, while press/tap without drag changes nothing and panel content never starts that gesture. Media reveals before the Search, location and layer controls fade near the screen top. The floating `概览/天文` rail has no inner vertical gap, and the shorter lower pill retains `想去/分享/云观星`. Ordinary unavailable values render the common visible copy `暂无数据` while their distinct domain/recovery states remain intact. Map uses one `none | spot-panel | layer-sheet` bottom-presentation owner, so opening layers clears the panel's presentation/active state, and a marker selected from an open layer sheet retargets directly to a new medium panel without restoring an intermediate old panel.

Panel and My entries converge on this same form owner and only differ in supplied context.
