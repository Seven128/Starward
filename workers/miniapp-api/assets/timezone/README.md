# HKSAR district boundary publication

`hksar_18_district_boundary.json` is the unmodified 18-district GeoJSON publication from the Home Affairs Department of the Government of the Hong Kong Special Administrative Region, obtained through [DATA.GOV.HK](https://data.gov.hk/en-data/dataset/hk-had-json1-hong-kong-administrative-boundaries/resource/c3810fd6-7b47-40f8-91bc-3e5bc9618cc8) on 2026-09-26. The direct source is <https://www.had.gov.hk/psi/hong-kong-administrative-boundaries/hksar_18_district_boundary.json>; the department's [data specification](https://www.had.gov.hk/datagovhk/dataspec/en/dataspec_district_boundary_en.pdf) identifies the boundary coordinates as WGS84 (EPSG:4326). The Government and Home Affairs Department own the source data; DATA.GOV.HK provides it under its [Terms and Conditions](https://data.gov.hk/en/terms-and-conditions), which require source attribution on copies and permit reuse. SHA-256: `ab2123b5a48c2e39e29ce594a0c51590cf6081922ab2c5c14ff78338b788f760`.

The Mini Program API uses this snapshot solely to distinguish the HKSAR side of the narrow Hong Kong/Shenzhen trial-region band when resolving a browsing map point's timezone. District membership is not a general IANA timezone database and does not establish offshore timezones or coverage outside the declared trial region. Refresh requires reviewing the source, verifying representative points on both sides, updating the pinned hash, and retesting the release artifact. The release Dockerfile already copies the API `assets/` directory alongside compiled code.

## Macao timezone feature

`asia-macau-2026d.geojson` is the `Asia/Macau` feature extracted without coordinate changes from the comprehensive `timezones.geojson.zip` asset in [Timezone Boundary Builder release 2026d](https://github.com/evansiroky/timezone-boundary-builder/releases/tag/2026d), which is built from [OpenStreetMap](https://www.openstreetmap.org/) data. The source archive was obtained on 2026-09-26 (SHA-256 `f72a40a0d00ef4464ad5f6dee85e0bf727e3fbe5ade360d8830f5a1db7d5f44b`); this extracted feature is SHA-256 `56cef0b6e06b101906528b167d39aa48a7af14ce80f971d350f65db35f0f9c58`. The extracted database is made available under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/); its license text is copied in `ODbL-1.0.txt`. Attribution: **Contains information from Timezone Boundary Builder and OpenStreetMap contributors, made available under ODbL 1.0.**

This approximate timezone geometry has four polygons and is used only inside the declared Mini Program trial rectangle. It is not an official administrative boundary or a proof of maritime timezone. The API pins exact bytes, exposes the source and license with Macao browsing contexts, and the Map displays the required attribution. Refresh requires updating this asset, its checksum, source version, representative Macao/Zhuhai checks and attribution together. The source release notes describe comprehensive timezone identities separately from the variants that merge zones with the same current UTC offset; this product preserves `Asia/Macau` as its own identity.
