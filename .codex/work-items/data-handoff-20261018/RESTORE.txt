   Verify both archive SHA-256 values against that manifest before extraction.
2. Expand-Archive -LiteralPath <runtime.zip> -DestinationPath <new-runtime-dir>
   node <handoff-dir>/restore.mjs verify --directory <new-runtime-dir>
3. node <handoff-dir>/restore.mjs decrypt --repo <repo> --input <private.zip.enc>
      --key-file <separate-private-key-file> --sha256 <encrypted-package-sha256>
      --output <fresh-private.zip>
   Expand-Archive -LiteralPath <fresh-private.zip> -DestinationPath <new-private-dir>
   node <handoff-dir>/restore.mjs verify --directory <new-private-dir>
4. Prepare a fresh, owned local PostgreSQL 17 instance with the existing owner.
   Put these four fields in an access-restricted JSON file, using that instance's
   own credentials: MINIAPP_INFRA_MODE=external, MINIAPP_ADMIN_DATABASE_URL,
   MINIAPP_INFRA_REDIS_URL and MINIAPP_POSTGRES_BIN_DIR. Values never enter logs.
   The existing owner requires a loopback host. Choose an unused database name:
   node <handoff-dir>/restore.mjs restore-db --repo <repo>
      --private-root <new-private-dir> --infra-config <private-config.json>
      --target starward_restore_r6_20261018

   MINIAPP_DARK_SKY_DATASET_VERSION=eog-vnl-v22-2025-gba-fixed-20261017-r6

   MINIAPP_MEDIA_STORAGE_ROOT=<new-private-dir>/media

   WECHAT_REMINDER_DELIVERY_ENABLED=false
