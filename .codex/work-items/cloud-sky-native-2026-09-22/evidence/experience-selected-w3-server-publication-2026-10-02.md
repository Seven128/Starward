## Contract and ownership

`GET /v2/sky/deep-sky/selected/{reference}?imageVersion=source-finite-v3` returns bare `DeepSkyImageDiscoveryData` with `no-cache`. It supplies one current admitted object, not a claim of all-object coverage: publication/source identity and notices, centre/orientation, three immutable level descriptors with actual filename/hash/encoded bytes/format/dimensions/field, unknown scientific coverage, and only actual published nonfinite/display metadata. Missing entry is 404; unknown version is 400. `assertDeepSkyImageDiscovery` binds requested reference, source/publication, exact canonical URLs, level dimensions, SHA, availability counts and byte-bound display support. Descriptor admission is not scientific/absolute-astrometry/quality acceptance.

The new `/v2/sky/deep-sky/{publicationHash}/{M-n}/{exact-filename}` route calls `getByFile`, which resolves only an exact level in a current/allowed raw publication and uses the shared full local-byte read/hash/format admission. It does not crawl disk, expose scientific frames or fetch upstream. Its descriptor/headers use that publication's own `displaySupport` snapshot, including absent older refinements. It never inherits current support simply because encoded bytes match.

The old selected GET/query/full-manifest routes are unchanged: omitted image version remains legacy v2; four previous publications and old JPEG downloads remain readable. Legacy `get()` still permits its existing same-byte PNG display refinement, separated from the new immutable path. An archived source id does not become current merely because the encoded file is shared.

API/static response headers share `skyPublicAssetHeaders("deep-sky", ...)`: immutable caching, MIME/source, field/pub/source-id/pixel size, and only applicable published missing count/display support. Canonical JSON display support is bound to the selected source SHA. The root-owned static bundle safely escapes this header; actual Caddy parsing/placeholder/JSON roundtrip belongs to the root's separate runtime evidence.

The actual transport operation source is `packages/miniapp-contracts/api/miniapp.operations.json`. Two new discovery/immutable operations use `responseEnvelope:false`; the existing two actually bare selected-image/full-manifest operations were corrected to that same flag. The generator was run and checked current. Existing barrel exports already export the type/function owner; no parallel contract module or generated-file hand edit was introduced. Root owns the subsequent client cache/decode integration.
