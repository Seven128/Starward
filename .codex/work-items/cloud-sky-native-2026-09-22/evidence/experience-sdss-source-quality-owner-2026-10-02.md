## Responsibility and controlling references

New production owner `data-pipelines/deep-sky/sdss_frame_quality.py` reads the four byte-bound existing core-field quality files and provides spatial PSF kernels, native diagnostic pixel flags and cross-source association. It reuses `sdss_corrected_frame._identity` and `_json_value` rather than defining a second field identity. Its pixel stencil uses root's shared `sdss_source_stencil.source_pixel_stencil`, the same four-neighbour geometry/index owner now used by gri scientific bilinear sampling. It neither applies flags to science nor changes availability/weights/RGB.

The acquired inputs and immutable original/readback receipts are documented in [core-quality input evidence](experience-sdss-core-quality-inputs-2026-10-02.md). The actual wire/coordinate research and its controlling offset correction are in [independent format facts](experience-sdss-mask-psf-capability-independent-2026-10-02.md), including `output/sdss-mask-psf-capability-independent-1002-r2/coordinate-addendum.json`. Standard format/mathematical facts informed an independent implementation. No GPL/unknown-licensed archive code was copied, compiled or adopted; no new library was installed. The mature BSD PyDL reference was considered, but its published transpose and first-row orders conflict with the verified wire/call-chain semantics, so it is not the numerical oracle.

Public interfaces are:

- `read_cached_psfield(path, expected, *, max_uncompressed_bytes) -> PsfField`; expected field identity, canonical source URL, raw bytes and SHA256.
- `read_cached_fpm(path, expected, *, max_uncompressed_bytes) -> PixelFlags`; the same receipt with band identity.
- `PsfField.reconstruct(band, x, y) -> float64 signed relative kernel`; native source array zero-index column/row, all actual basis rows, no clipping/normalization/shift.
- `PixelFlags.flags` is a read-only native uint16 array; `enum` preserves actual plane names/indices and sentinel. `stencil(x,y) -> FlagStencil(flags, geometry)` ORs four neighbours using the shared owner, even at zero interpolation weight. Outside geometry has zero bits with `geometry=false`, an unknown/unavailable stencil rather than a good-pixel certificate.
- `check_frame_quality(frame, psfield, flags) -> dict` correlates admitted field/rerun/camcol/run, mask band and native shape; present PS_ID values must agree, missing facts remain unknown. It returns complete expected identity, three source hashes and actual PS_ID values with `availability=NOT_ASSESSED`, `quality=UNKNOWN`.

Receipts remain ordinary JSON dictionaries/lists, compatible with current QC writers. Typed basis/kernel/flag arrays are read-only. The association helper does not copy, alter or assess frame samples.

## Admission, scientific meaning and supported format

Each reader requires exact canonical filename and SDSS URL, real raw byte count/SHA256, a bounded raw read, and complete bounded FITS/table/heap readback. fpM requires one complete gzip member with CRC and no trailing member/bytes. Every variable descriptor is checked before its array is forced; the sum of expanded variable payload bytes also cannot exceed the caller's uncompressed-byte cap, protecting against many descriptors aliasing one small heap. This bound is independent of basis count. Actual raw header core identity must match; absent RERUN/FILTER is never filled from a filename. Canonical provenance and actual header facts are recorded separately.

PSF reads the actual primary u/g/r/i/z order and all dynamic basis rows, preserving declared per-row orders. Actual wire `C[rowPower,columnPower]` is not transposed by Astropy. Native coordinates become PHOTO pixel centers through `(y+.5)*.001` and `(x+.5)*.001`; each basis gets its own declared polynomial sum before signed eigenimage combination. Only declared terms must be finite. Real r/z NaNs in inactive padding remain preserved and unused. Actual kernels have supported 51×51 geometry, RTYPE128 and zero eigenimage region origins; unsupported variants fail explicitly. The receipt retains status64/SPARSE and unknown spatial quality. The relative kernel is not a calibrated flux image, FWHM, measured-star validation or a PSF correction.

fpM decodes verified big-endian signed-int16 `(row,left,right)` triples and inclusive endpoints. Every object must have canonical ordered nonoverlapping/nontouching runs, exact `6*nspan` heap length, matching local bbox and sum/unique inclusive pixel count inside native 1489×2048. Different objects are ORed and may overlap; object sums never substitute for union counts. The actual enum determines plane bits 0–9; value10 S_NMASK_TYPES is a sentinel. Reference counters are retained as bookkeeping and do not contribute to quality or weights. This first bounded path accepts the actually observed zero object offsets and nonempty objects; nonzero offsets and serialized nspan0 objects fail explicitly. Empty planes are supported. The verified general format's object-offset arithmetic is documented, but has not been silently implemented from the all-zero cached case.

Flags such as OBJECT/INTERP/CR are diagnostic information, not an automatic rejection policy. Scientific finite zero, signed negative or nonfinite samples retain their existing independent sampling meaning. No default mask policy, PSF matching, deconvolution, background subtraction, colour mapping or publication promotion was added.
