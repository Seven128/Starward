# 本轮非真机剩余义务核对

依据当前 [PLAN](../PLAN.md)、完整 [REQUIREMENTS](../REQUIREMENTS.md)、商业 [SCOPE](../SCOPE-CHANGE-2026-09-23.md) 和现行 Context 核，以下是下一次恢复时的依赖，不是降低完成条件。用户要求尽量先做非真机，当前没有占 Android、微信开发者工具、共享 8787 或活动 WEAPP 输出。局部测试与历史桌面像素不能升级为目标运行时验收。

| 模块 | 本轮可独立推进及实做 | 仍需的具体输入/目标证据 |
| --- | --- | --- |
| A/B1/B4 | 原计划对应数据、报告/Canvas、身份/交互非手机链已有定向证据；本轮新增两颗本体轴通过正式点 HTTP、坏轴客户端降级与现有同帧/点选消费者检查，没有发现需要改公共 owner 的新反例 | Android 来源页返回 Canvas 旧失败、普通控件与新 shader 合成、实际手势/姿态/读屏；P1。整页峰值/官方包体仍缺设备与官方工具 |
| B2 | OPAL 冰巨星条带只在任务 evidence，加工器故障时留旧；候选缺测纬度已采用二值透明掩码，BFF 可选同刻轴与 NASA 1-bar 扁球盘面已接，旧缓存保留球面；JPL Horizons 独立亚观测点经纬已数值核轴向 | 历史增强色的科学精度、正式图像清单/来源披露及目标 shader 的纬度采样/透明回退、微信原生像素仍缺；现有土星新 GLSL 尚未在目标机最小编译，先按 P1 核平台假设后扩纹理消费者。金星/太阳的现时自然彩、活动或大气不能由固定候选图推定 |
| B3 | 再核 `SpotSummary` 只有 WGS84/GCJ02 点与可空海拔，`SpotSiteData` 无观测站位/位置误差/海拔来源；Map 产品只发布俯视 RGBA，不含数值 DEM。既有真实 COG 探针在约100m偏移下山脊角差最多4.713° | 需要经审核的实际观测站位与水平/高度误差、适用数值 DEM 覆盖及近场遗漏边界 P2；否则保持几何地平线，不把模型山脊当现场遮挡。现有固定晴空示意不能宣称当地大气实测；目标像素/性能仍 P1/P4 |
| C | 商业客户端 TRIAL 门禁已有，W3/2MASS不是光学全天替代；本轮未扩大光学来源 | PS1/SkyMapper 自托管、加工、再分发和实际可取得的图像/成本尚无新的具体证据 P3；不以 CDS 试验瓦片或下载可得性冒充准入。DSS/Gaia/ESA成品及商业动态卫星/小天体按用户决定不做 |
| D | 现有发布镜像/本机负载/边缘分类和成本输入已核，本轮 Context 校验与相关类型/合同/故障回归通过 | 远端正式环境和真实计费、Agent现金、官方微信包体和手机峰值 P4；部署归档实际命令曾遭自动审批策略拒绝，不能绕行宣称实测；最终独立审查 P5、Android/iOS 综合验收及发布授权仍开放 |

因此本轮没有把缺站位的数据结构猜成精确地景，没有把历史色带放进正式包，也没有以旧手机预览证明新增 shader。下一项按 PLAN 的 P1 最小平台风险检查；手机当前由用户使用，不主动占用。若在设备可用前出现可核的 P2/P3/P4 新输入，按对应模块重开非手机工作。
