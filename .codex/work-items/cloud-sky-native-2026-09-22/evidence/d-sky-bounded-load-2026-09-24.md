# D 隔离发布镜像的有界 Sky 请求与资源测量（2026-09-24）

## 场景与边界

复用现有 [504视角 SAO 选片探针](sao-twilight-selection-2026-09-24.md)的同一真实 BSC v3/SAO v2 资源、深圳 22.5/114.5/20m、2026-10-08T13:00Z、太阳高度 -18°、390×844；[本轮选片脚本](../d-sky-load-selection.mts)取这组采样中出版字节最多的一视角：FOV 5°、俯仰 -30°、朝向 270°，17 片、出版物原始 1,109,570 B。此为限定的暗夜窄视角，不是全部用户视角；它遵守 Mini `sky-stellar-tile-loader.ts` 的每端 3 个并发分片请求上限。

用当前 Mini API 发布镜像和 pin 的 Caddy 2.11.4 镜像在专属 Docker network、`127.0.0.1:18791` 跑四个并行模拟客户端；API/Caddy 施加现有 Compose 的 512/128 MiB 容器限制。冷窄视角每端取 BSC v3、SAO v2 index、17 片；热视角以各自 ETag 对同样资源重取；独立广角极端场景每端取 W3 manifest 和 12 张全穹 order-0 瓦片。W3 全 12 片只在总览选片可达，不与 FOV 5° 的 SAO 最重视角并作单次真实画面。脚本 [选择结果](d-sky-load-selection-2026-09-24.json)、[请求与边缘日志汇总](d-sky-load-probe-2026-09-24.json)，源脚本见 `../d-sky-load-probe.mjs`。

| 隔离阶段 | 4端合计请求 | 本机墙钟时间 | 边缘实际响应体 |
| --- | ---: | ---: | ---: |
| 暗夜窄视角冷 BSC+SAO | 76次 200 | 453 ms | 4,575,660 B |
| 相同资源条件重取 | 76次 304 | 54 ms | 0 B |
| 全穹 W3 基础层冷请求 | 52次 200 | 73 ms | 2,720,256 B |

W3 每张返回仍逐字节核对清单长度与 SHA；星表/SAO 检查正式状态、非空响应和条件304。Caddy 访问日志在这 204 个请求中只有固定类别、状态、`size` 等过滤后字段，没有 request/response headers。API cgroup 本次容器生命周期的 `memory.peak=146,898,944 B`、停止前 `memory.current=116,088,832 B`，限额 536,870,912 B；Caddy 分别为 29,687,808 / 29,634,560 B，限额 134,217,728 B。两者 `memory.events` 的 `oom=0`、`oom_kill=0`，停止前仍运行；没有提权、触碰共享 8787、用户容器/IDE、手机或活动 WEAPP 产物。专属 `--rm` 容器和 network 已停止/移除。

这些时间来自本机 loopback+Docker，包含本机 Node 客户端和当前进程缓存；没有真实 3Mbps 云主机、微信网络/缓存、生产 PostgreSQL/Redis、QWeather 或其它同时访问，也没有 GPU/手机内存、首屏实际请求序列和持久峰值监控。4 个相同视角同时取数不是 DAU 分布，304 必须由客户端实际发送条件请求才能出现；图片 immutable 可能在客户端直接命中而不发请求。当前结果只表明限定场景在本机资源上未触发瓶颈，不能把 453 ms、147 MB 或 0 B 热响应外推为生产容量、云月费、设备峰值或 V05 验收。
