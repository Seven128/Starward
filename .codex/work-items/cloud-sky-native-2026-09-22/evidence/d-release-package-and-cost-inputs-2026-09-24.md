# D 发布控制包与 K02 费用输入界限（2026-09-24）

## 发布消费链

正式 staging 和 production 工作流都用同一 `tar ... tools/deployment infrastructure/deployment` 命令构造控制包，远端 `run-remote-promotion.sh` 先核归档 SHA，再解压为按 revision 固定的 control 目录，随后由部署程序从该目录读取 Compose。新增 `sky-resource-logging.caddy` 位于被归档的目录内；正式及 operator-preview Compose 都把它只读挂载至 `/etc/caddy/sky-resource-logging.caddy`，对应 Caddyfile 都 `import` 该绝对路径。针对两个工作流和两套 Compose/Caddyfile 的契约检查 13/13 通过；两份实际 Caddyfile 曾用 pin 的 Caddy 镜像 `adapt --validate` 通过，隔离 HTTP 日志已有 [实测](d-sky-egress-classification-2026-09-24.md)。这些是**工作区候选**，新文件仍未提交，不是已发布到远端的控制包。

本机临时 `tar` 归档并列清单的命令被自动审批策略拒绝（工具仅返回 `blocked by policy`，未给细因）；没有把静态包含关系写成该归档的实测结果，也未尝试绕过审批。正式 CI 归档清单、远端读取/启动和账单需在授权发布路径另验。

## 可用费用输入与缺口

| 项目 | 当前可复核输入 | 仍不可推定的量 |
| --- | --- | --- |
| 数据获取与加工 | 当前在用静态源 1,938 文件、125,921,895 B，见 [字节审计](d-current-byte-audit-2026-09-24.md)；已有 BSC/SAO、固定图、W3/2MASS 的加工与出版路径 | 原始下载/计算等待、生产再加工频率与计算/人力现金；PS1/SkyMapper 商用自托管条件仍未确认 |
| 云存储及备份 | 上述字节只是工作区源库存，镜像中出版形式可核 | 云副本数、备份/快照/生命周期、计费容量与现行单价；不能按 125.9 MB 直接计费 |
| 分发流量与请求 | [当前发布镜像 HTTP](d-release-http-2026-09-24.md)核指定正式资源；[隔离边缘负载](d-sky-bounded-load-2026-09-24.md)四端冷 BSC+SAO 4,575,660 B、条件 304 为 0 B、单独全穹 W3 冷 2,720,256 B；日志现能按固定资源类别聚合状态和出口 `size` | 真实访问分布、每日人数/会话、视场/时刻组合、用户端缓存命中、重试、CDN（当前配方无 CDN）、网络及云侧计量与现行单价；冷/热样本不是每人每日或月量 |
| 服务运行 | 本机受限容器 API/Caddy 峰值约 147/30 MB，详 [有界负载](d-sky-bounded-load-2026-09-24.md)；独立 PG/Redis 重启链详 [组合证据](d-current-release-postgres-2026-09-24.md) | 正式并发/峰谷、PG/Redis/边缘实例规格、备份与监控、QWeather 正式调用、实际云实例时长/费用 |
| Agent 开发与项目方参与 | 旧研究的 168–352 Agent 有效小时、项目方 8–16 小时及条件原始加工 32–80 小时均为未校准**历史情景**，见 [REQUIREMENTS K01](../REQUIREMENTS.md)；旧情景含现商业版已暂缓的动态对象，不能当剩余范围估计 | 实际 Agent 运行/收费口径、已发生与剩余有效工时、项目方投入和现金；小时不折算人民币，也不并入云月费 |
| 逐项商业授权 | 当前商业范围不安排新增逐项授权费；DSS/Gaia/ESA 成品图和实时卫星/小天体已按范围决定退出 | 未确认来源不得以“免费下载”假定商用分发权；不以零元替代数据和运维支出 |

[旧成本模型](../../stellarium-cost-research-2026-09-22/cost-model.json)的 1,000 DAU、每日新增 30 MB/人、500 GB 存储与缓存、约 318 元/月只是 2026-09-22 情景，不是当前商业范围、真实用量、最新价格或全天高清成本上限。当前没有把本机请求样本乘以 DAU，也没有刷新旧模型覆盖原始文件。后续有权的真实预览/生产流量、云计量及 Agent 收费凭据出现后，应分栏代入并核当时供应商正式价目；此前 K02 维持未验收。

2026-09-25 补充：M51 当前拓扑是镜像内原图→同机 API→Caddy→Lighthouse 公网，未使用 COS/CDN；旧 COS/CDN 单价情景不适合作当前 M51 实际账单。三图 64,352 B、已购主机300GB/月共享公网出站包、当前官方内地超额公开目录价0.8元/GB和缺失的实际账单/访问频率见 [C/P4获取与费用边界](c-sdss-acquisition-cost-2026-09-25.md)。没有将套餐全额分配给云观星，也未把未知增量费用写零。
