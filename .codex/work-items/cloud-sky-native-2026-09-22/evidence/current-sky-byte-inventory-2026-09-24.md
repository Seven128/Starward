# 2026-09-24 当前云观星静态文件字节基线

从当前工作区正式服务资产与两个在用 BSC 版本直接按文件字节求和，不含 `terrain`（当前不作 Sky 真实地景）、已退役 Gaia/HIP 资产、未获权的 PS1/SkyMapper TRIAL、编译代码/依赖、数据库、日志、备份、云对象副本、HTTP 头与传输压缩。本表是**本地已接入静态文件的容量下界/构成**，不是全天高清巡天容量或云账单。

计算方法：在 `workers/miniapp-api/assets` 中逐目录递归列文件，对 `celestial-names`、`celestial-names-v2`、`constellations`、`deep-sky`、`jupiter`、`mars`、`mercury`、`moon`、`sao`、`sao-v2` 的 `Length` 求和，得 120,782,639 B；再加 `packages/astronomy-core/data/bsc5p-bright-stars.v2.json` 与 `.v3.json` 共 5,136,353 B。旧客户端仍依赖 v2/v1 路径，不能为减容量直接删旧版本；两版 SAO 的源包与分片重复占本地文件，实际云存储去重/部署分层尚未测。

传输量仅可给有条件的原始字节算例：新客户端若首次下载 BSC v3 JSON 2,568,178 B、SAO v2 index 281,063 B，且进入已测 504 视野中最高选片的夜间视角，分片原始字节 1,109,570 B，三者合计 3,958,811 B/次冷缓存路径；1,000 条这样的路径合计 3,958,811,000 B（约 3.96 GB 十进制），**不是 DAU 平均或 CDN 计费量**。暮光可不选 SAO 暗星，缓存命中、压缩和实际浏览次数会改变传输；天气、搜索、图像、请求开销另计。固定 2MASS 图 703,555 B、月面 372,399 B、火星 94,411 B、水星 89,984 B、木星条带 1,026 B，均按实际打开视角与已缓存状态单独发生，不能机械叠加为每个用户必下载量。

现有成本研究中的 500 GB 存储、30 MB/人/天是假设场景，**不是当前资产实测值、全天高清上限或最新报价**。现金仍须分别测首次数据获取加工、部署复制/备份、对象存储、云/CDN 传输与请求、服务算力、Agent 平台实际新增支出；Agent 有效工作时间与项目方参与另计。当前未做生产云部署，不能按本表计算最终月费。
