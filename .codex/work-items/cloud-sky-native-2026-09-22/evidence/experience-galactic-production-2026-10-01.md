## 共享机制与收益

由既有完整投影圆帽围住 viewport 所有采样射线，再按原银河球面轴转换为保守源像素窗口。接缝或极点保全经度；地平和黑色像素不缩科学覆盖。原滤波的相邻采样及数值边界纳入窗口，向外对齐像素块以复用相近视场。GPU owner 用 WebGL1 标准 FBO + `copyTexImage2D` 保留原 texel，退休临时完整源纹理；原生 bitmap 仍是完整图，未在 CPU 裁图/重采样或新增解码缓存。Core API 依据见 [WebGL 1.0 specification](https://registry.khronos.org/webgl/specs/latest/1.0/)，实际平台支持另以下方原生证据为准。

单一 decoded identity Map 保存实际驻留窗口；需求被已有窗口包含时复用。全天返回局部时从已有完整 GPU 纹理复制后退休完整纹理，避免再次原生上传。相同预算下，优先保留需要整幅源上传才能重建的局部驻留；随后仍按原预算裁退。上传失败、明确重试、新解码身份、上一帧保护、hide/代次/退休由原 owner 保持，未让字节压力隐式重试失败图。可选复制能力失败时保有效完整纹理并在该 GPU owner 内关闭复制路径，独立星点/图层继续；context loss 仍由生命周期恢复。
