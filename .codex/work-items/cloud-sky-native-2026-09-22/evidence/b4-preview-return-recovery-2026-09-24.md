# B4：时间预览、跟踪恢复与返回入口

本轮继续沿现有页面编排、公共 Observation Context、天体位置和跟踪 owner 核实际消费者，没有新增时间/地点或对象身份来源。以下是非手机开发证据，不替代原生 Back、触摸、屏幕阅读器与 Canvas 合成验收。

- 上下文错误页原本两处动作直接 `switchTab` 地图，而普通 Sky 和加载页优先 `navigateBack`。从观星点进入后若 Context 不完整，错误页会丢掉实际入口。现在三种页面状态复用 `returnToSkyEntry`，先返回导航栈，只有栈不可返回才切地图；错误提示改为核对原入口。真实页面回调回归修前失败，修后验证成功和兜底路径。
- 跟踪目标目录未就绪时，原“重试位置”仍强制 `refetch` 一个以空目录构造的查询；禁用查询可被手动 refetch 触发。现在先重试天空/目录，目录可用才重试绑定版本的位置，按钮文案区分“重试星图/位置”。实际组件按钮回归修前失败，修后验证两个阶段。
- 未提交时间预览中的真实天空标签可以打开天体详情并执行定位/跟踪。原位置动作收起时间轴但不取消预览，临时时刻会失去可见提交/取消入口。现在预览定位/跟踪保留公共时间轴；已提交时刻的定位仍可收起。真实页面动作回归修前失败，修后覆盖定位与跟踪。页面现有时间轴收起/切换仍取消预览，Context 提交仍由已有异步会话负责。
- 额外以页面实际帧/日历选择声明核跨午夜：Asia/Shanghai 23:30→次日00:30 的预览选择精确报告帧与次日日历日期；取消回到原帧和原日期。这是确定性本地组合检查，不是手机视觉观察。
