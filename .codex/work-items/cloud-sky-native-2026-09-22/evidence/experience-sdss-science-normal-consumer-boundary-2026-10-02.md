## Exact science TAN: reusable boundary and precision scope

Science geometry must use full `sciencePublication.center` and each actual level's `fieldDegrees`, `pixels`, `crpixFitsOneBased`; it must not use rounded deep-catalog centers or the old `DeepSkyScenePoint` horizontal north/east samples. The publisher's WCS is ICRS north-up/east-left: `sdss_gri_tan.py:85` sets centered CRPIX and `CDELT=[-step,+step]` with `step = degrees(2*tan(field/2)/pixels)`, and saved PNG rows reverse FITS north/south rows. This is a fixed linear-TAN approximation; it does not claim improved source astrometry.

Reuse `exactSkyObservationFrame(data, frameAt)` / `skyEquatorialDirectionToEnu` (`sky-observation-frame.ts:16/:6`), already used for independent optical HiPS and J2000 grids. These select the same validated report observer/time matrix independently of the deep catalog. A minimal science registration owner can form analytic EQJ center/east/north vectors from the exact publication RA/Dec, construct the actual raw affine TAN plane including each level's CRPIX/scale, and apply that **same** matrix. No new Astronomy Engine call, horizontal rounding, offset sample or independently re-orthogonalized transform is required. Missing/invalid same-frame observation geometry remains unavailable, rather than fallback to a stale catalog anchor.

`registerSkyArtwork` (`sky-artwork-registration.ts:34`) currently accepts unit direction anchors and recovers an affine plane through them. Three individually normalized arbitrary TAN corners lose their original homogeneous lengths; the existing `sky-artwork-registration.test.ts:57` test explicitly records failure to reproduce an asymmetric fourth corner. Current v2 fixes 512 pixels, centered CRPIX 256.5, square centered crop: with an ideal orthogonal matrix, three symmetric corners have the same raw length, so normalization preserves this particular plane. However `assertStellarRotation` allows numerical deviation of `1e-6`; separately normalizing actual transformed corners is not an exact projective proof for every admitted matrix.

Root's proposed shared raw-plane entry `registerSkyArtworkPlane({uv, point})` is the minimum coherent extension to the existing inverse/UV/corners/bounds owner: preserve raw finite nonzero plane points, keep old unit-ray input validation/thresholds/math unchanged through delegation, derive corner/bound directions only after plane interpolation, and avoid duplicating matrix inversion or bounds in the science owner. This is a review of the **proposed** boundary, not a claim that the function exists or has passed checks. It requires independent off-anchor/fourth-corner and actual publisher-WCS comparison, including an admitted slightly non-orthogonal matrix; three-anchor equality alone is insufficient. Normal group/source adoption still depends on the separate contribution/FBO feasibility and full consumer cases above.
