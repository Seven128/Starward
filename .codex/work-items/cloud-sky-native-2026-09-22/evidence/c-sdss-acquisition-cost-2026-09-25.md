# C/P4：SDSS M51 固定图获取节奏与当前出口费用边界（2026-09-25）

## 当前这条链实际怎样工作

正式 M51 出版清单固定三个 DR17 SkyServer ImgCutout 请求 URL、原图 SHA、尺寸与来源；三张原 JPEG 合计 **64,352 B**，仓库清单原文件 **2,282 B**。`processing.runtimeNetwork=forbidden`，BFF 从镜像内文件校验并提供 hash-bound HTTP，Mini 只访问自有 BFF；每次用户打开、放大或重试都**不**访问 SDSS。三次源站取图是本轮一次性离线出版输入，不是每用户或每月一次；未来替换某一出版物应重新审核原图/哈希、质量、几何、署名与变更说明，发布频率目前没有产品事实可定。当前本机正式镜像包含这四个文件，边缘实际三图 HTTP 200/逐字节 SHA 已核；[真实 HTTP 与出口类别](d-sdss-release-egress-2026-09-25.md)。还没有远端发布或目标微信请求轨迹。

[SDSS DR17 官方批量获取说明](https://www.sdss4.org/dr17/data_access/bulk/)对成像资料给出 SkyServer 搜索或 `window_flist.fits` 定位 `RERUN-RUN-CAMCOL-FIELD`，再从 SAS 下载对应校准 FITS 帧的路线；[官方 FITS 教程](https://www.sdss4.org/dr15/tutorials/retrievefits/)说少量地点可查字段，很多字段宜使用批量下载工具。这为**将来扩大采集**提供不同于逐视角公共 ImgCutout 的正式技术入口，但不构成当前已完成覆盖、RGB 加工、像素质量、源站容量或生产成本证明。ImgCutout 自身三张 M51 样本可用；未找到可支撑大规模持续公共 cutout 调用的明确配额，不能据小样本推批量能力。PS1/SkyMapper 的权益门禁仍独立关闭。

## 当前部署配置与现金口径

现有 `infrastructure/deployment/compose.yml` 把 API 及出版文件放进同一 release 镜像，Caddy 直接反代同机 `api:8787`；正式 `Caddyfile` 启用 zstd/gzip，但**没有 COS 或 CDN 资源出口**。镜像本机 `docker image inspect` 返回 144,905,743 B；这是整个镜像，不是 M51 增量、TCR 实际计费容量或远端镜像。三张图的 64,352 B 是当前源字节及本机 `Accept-Encoding: identity` 边缘响应体，非手机网络/TLS总量。

现有项目 Context 记录已付上海 Lighthouse **109 元/年**、4核/4GB、3Mbps、40GB SSD、**300GB/月**；这是整个项目的已购第一台预览/迁移主机，不能全额记作 M51 增量或宣称它能承载公开流量。[腾讯云 Lighthouse 计费概述](https://cloud.tencent.com/document/product/1207/44368)说明套餐按实例公网**出流量**计费，超出月包按量收费；[官方价格总览](https://cloud.tencent.com/document/product/1207/73452)当前列中国内地套餐外出流量 **0.8 元/GB**。这两条为公开目录价，不替代本账号实际账单、折扣、账期和额外存储/备份/TCR 计费。没有启用 COS/CDN 的当前 M51 路径不应按旧研究的 COS 请求费、COS 出口费与 CDN 命中率叠加估价。

可复核的增量公式只能写成：在**同一实际计费周期**，`M51 额外出口费用 = 超出套餐部分总账单（含 M51） - 不含 M51 时超出套餐部分总账单`；需供应商实际出站计量和其它业务基线。当前 Caddy 的 `optical_published`、状态及 `size` 可给响应体分项，但不含 TLS/报文开销、其它 API、缓存未发请求，也没有可抵账的整月保留记录。即便把 64,352 B 乘请求数，也只能形成源体情景，不能得出实际现金。3Mbps 的理想链路对三图全取至少约 **0.172 秒**串行出口时间（64,352×8/3,000,000）；不含 RTT、竞争、编码、客户端解码或 GPU，不能视为真实加载时延和容量。初期若考虑外部对象存储/CDN，必须先改变部署拓扑并另算副本、请求、缓存与流量；目前它们只是未采用选项。

## 仍缺的可结算证据

- 云控制台/账单的实际月周期、全部出流量、超额账单、备份/快照、TCR 与其它服务费用；当前没有凭据支持读取，未把未知写零。
- 同一固定 Mini 候选的真实请求序列、缓存/重试、按类别出口与设备解码/峰值，以及公开访问分布；当前本机 HTTP 不能代替。
- 若扩 SDSS 目标：真实字段覆盖与 g/r/i 有效像素、SAS 原帧取得/加工耗时及产物大小、镜像/云副本、CDN 是否有必要，再按当前公开单价和账单重新评估。单目标 M51 不是全天高清成本上限。
