# WeChat Mini Program Spot Information And Sky Invariants

This on-demand subdomain node normatively continues `Cross-Control And State Invariants` for continuous spot information, astronomy evidence, full-sky orientation and the source-lift focus family.

## 云观星采用资源

当前原生场景已接入可开关的通用模拟草地、远景轮廓与近景树木候选，沿用所选时刻的太阳位置、真实几何地平线、相机及普通/红光模式。GPU绘制和点选共用同一原创虚拟几何；标签使用已提交的相机与已绘地景状态，不能把被模型遮住的中心当作可见星点或用后到帧遮挡旧页面投影。部分露出的已解析盘面或土星环仍可按实际形状点选；明确定位辅助可以提示“模拟地景遮挡”，地平线以下另行说明。它不代表所选观星点实景，也不提供当地山体、近物或天气遮挡结论。模型接入和局部运行证据不等于环境完成；地平附近的空间层次、星空辨认、连续缩放与模式组合及目标质量/性能仍按完整参考体验评价，不以当前简化模型限制最终范围。

正常地景图片链现可通过自有版本化发布和共享原生图像/GPU owner显示 Stara Lesna Meadows 历史山林草地全景，程序模型保留为图片失败回退。遮挡、标签、点选和来源绑定实际成功绘制的图片alpha及同代相机；透空不继承旧树木遮挡，图片失败只能披露实际回退模型，并提供显式重试。来源保留作者、包内与目录的两种许可声明、派生条款、处理、当前图片及原包，详[外部能力](../../../../external-capabilities.md#云观星引擎选型)。图片方位只是虚拟ENU注册，不使用原包observer作为观星点或声称其为当前地点现场/测得真北；照片与程序回退复用`sky-landscape.ts`持有的同帧晨昏亮度曲线；曝光只作模拟，固定照片的阴影和高光不随当前太阳重建，不提供当地天气或可见性。当前1K/2K均接入，按其余已准备图片的共享GPU预算余量选档，其他图层尚在加载或尺寸未知时先保概览；细档下载/解码加载或失败保留有效粗图，公开重试后可恢复细图；共享owner区分GPU失败，地景公开重试在该失败时重建现有Canvas/GPU，普通下载重试不退休有效粗图。GPU图片程序失败必须报告其随后拒绝的粗图，不能把不可绘制的图保留为已可用或无提示锁死。每档图片必须配同档alpha，已绘来源据实际档位呈现；预算切回粗档不继续使用细档mask。共享注册图片可见性在小视场使用包含曲边的射线hull/凸锥边半空间作保守排除，不能因松散圆帽重上传实际视场外图片或靠删可见内容凑预算。原生局部加载/恢复和软件GPU共存证据仍不代表正式最终视觉采用、完整体验质量、native/GPU总峰值或手机性能完成。

完成且与当前publication／Canvas绑定的alpha，在构建mask时记录首个非零源行；`sky-landscape-mask.ts`复用既有完整球面视口边界，连同LINEAR邻居、一个源texel和float余量，保守证明高空视口没有地景贡献。`use-sky-landscape.ts`据每档自己的有效alpha选择图片需求，完全无贡献时不获取／解码该PNG；已有文件仍由原有界loader挂起和退休，低空／全天返回保概览与细档恢复。已取得alpha与尚未取得bitmap分开表达，实际scene／renderer按最终提交的相机重新检查：真实零贡献不回退成另一棵程序树，不改变地景开启意愿，也不把缺失mask当作透明成功。仍有可用粗图时优先使用其自身mask，已完成的细档透明alpha不能提前跳过粗图或改变粗图的遮挡／点选；无bitmap才使用独立已完成mask证明真实零贡献。mask跟随原Canvas代次守卫和sameScene，绘制／点选保相同源遮挡；未知／非法几何仍保守允许资源。它不是现场地形判断、新出版字段、缩图或预算扩大；目标内存／峰值及完整组合须独立测量。

影像来源必须随已提交的最终合成结果呈现。现有注册/相机和原创几何可保守证明整幅图或其视口部分完全被成功绘制的地景、不透明光学图覆盖时，应隐藏对应的可见来源；边缘露出仍保留。中心被盖或下载完成都不能单独证明全图是否呈现，复杂遮挡/边界仍需相应实际输出验证。地景/光学失败不得清除独立影像或冒称下载错误。M51精细层更新失败时，保留最近可用粗层及其真实视场/来源，提供与当前已绘图匹配的显式重试；相机变化不循环重试失败下载。来源列表的获取许可与本帧可见信用是不同职责；查看资料和独立来源返回应保留时间、视角、对象和适用影像。开发恢复证据不替代目标平台的配准、质量、资源与完整组合验收。

## Cross-Control And State Invariants

原生大气显示继续由同一已绘时刻的太阳方向、ENU相机和固定散射／显示近似驱动；太阳落地后的垂直梯度依据几何地影高度变化，间接光相对色调与多路径透射采用固定显示近似，由同一shader持有，未引入新引擎、数据图或运行库，也不表示完整多次散射或现场测光。`sky-gpu-renderer.ts`把指数曝光后的线性结果转换为sRGB，不再把界面深色调色板的逐通道上限当作模拟昼暮天空的亮度上限。深色Canvas基底、夜间分支和观测红光语义保留；模拟曝光/相对光谱不提供当地大气、现场可见性或实测光度，有限参照亮度改善不表示整场环境质量完成。普通模式可以呈现明亮环境叠层，原生白字状态栏和菜单必须仍有深色界面安全区：全屏Sky复用已有`nativeNavigationInsets()`的statusBarHeight/capsuleBottom，在GPU完成全部天体/图片/地景后，以当前帧基底和真实framebuffer尺度绘制两者的最大已知范围；它是界面表面，不是地景遮挡或第二套天空投影。缺失/无效尺寸不猜造安全区，不新增纹理、shader或逐帧平台测量；每帧恢复scissor状态，跟随同一Canvas生命周期退休。其余天空、界面覆盖与目标设备的完整可读/可操作组合仍须实际验证。

地平和赤道坐标网格是页面会话内的独立显示意愿，默认保留地平网格、赤道关闭；关闭坐标网格仍保留真实几何地平线。两者沿用当前观察帧、ENU相机、视口中心、普通/红光线段owner及实际地景遮挡。赤道网格使用报告的EQJ/J2000到ENU旋转，与银河及巡天共用转换；没有有效的当前时刻观察帧不能沿用旧网格，保持选择意愿并说明暂不可用，不把失效帧当空网格成功。校准编辑锁定显示开关。快捷设置区域的实际矩形与返回、通知、原生胶囊及底部控件一起参与全天圆盘避让；控件换行或状态说明变化后重测，隐藏/卸载及被替代的测量不得改写新视口。网格代码与开发检查不代表原生控件合成、目标性能或完整辅助层体验已验收。

方向控制器将页面前台寿命与跟随意愿分开管理：重复隐藏/显示不丢失已请求的跟随或重复获取原生流；隐藏后到达的重试只保留待恢复意愿，回到该页前台才获取。显式切手动会取消待恢复意愿。现有原生协调器仍负责串行获取/停止及迟到回调隔离，不增加第二套方向或校准来源；目标姿态/后台组合证据仍须在实际设备获得。Canvas排队帧与当前参照／校准／手动意图由 `sky-canvas-view.ts` 显式协调：参照代次变化拒绝旧姿态，编辑／待校准保当前冻结完整旋转，编辑采用正常对照尺度；普通同参照帧保自身姿态，手动／跟踪保自身意图。方向owner仍提供最新稳定呈现，`sky-browsing-camera.ts`仍单独持有总览／回程状态；同一结果的尺度／进度／中心供实际绘制与已绘快照使用，不另造传感器、校准或相机状态。
