# 另一台电脑：小程序开发工具与流程优化提示词

请在这台电脑当前已授权的 Starward worktree/分支中，直接落实微信小程序开发流程与工具调用的效率优化。先检查本地 AGENTS、Context、现有工具/skill 和未提交修改，复用已有实现，不创建新的 worktree、切换分支或覆盖其他开发成果。这是开发工具维护，不是重新执行产品 Goal 或创建新验收门槛。

## 要达成的结果

1. **核对当前真实能力。** 以本机安装的微信开发者工具、随附官方 `wechatide-skill`、公开 CLI 帮助和实际调用为准。区分已经接入并使用、工具支持但未验证、GUI 有而当前 agent 无调用入口。复用已有调研和有效证据；只有实质未知才补查官方或社区。不要把另一台机器的版本号、安装路径、端口、账号、AppID、令牌或历史成功抄成这里的事实。
2. **官方包与项目经验分开。** 审查已导入官方 skill 是否被本地修改；把有用补充迁到项目侧，完整保留原副本。项目侧只维护按问题选工具、会话复用、启动恢复与证据边界；不复制官方工具目录，不把自写内容伪装成官方原文。优先复用已有 `starward-miniapp-development` 或相同责任的 skill。
3. **实现自动单向同步。** 已安装开发者工具的官方包是本机来源；全局或当前 harness 仅有一份明确使用的官方副本。复用已有启动入口，首次进入微信开发或 IDE 更新后比较版本及文件摘要，有变化才整包同步。保留可恢复旧副本，保护本地修改、防止多个 worktree 同时替换同一全局包，不回写安装目录，不默认降级、不新增常驻监听服务。自动同步的是本机配套版本，不是网上独立最新版。先查已有 `tools/miniapp/wechatide-skill-sync.mjs`，若已有则适配本机，不另造同步器。
4. **处理发现与重载。** 同步文件并不等于 agent 已加载新版。核实此客户端实际支持的技能发现/重载方式，更新后读回新版说明；不能调用的协议不要编造命令。需要重载客户端时保留任务交接和未完成状态。恢复前不要凭旧说明执行新版接口。
5. **优先直接观察真实状态。** 布局/不可见问题按需读 WXML、样式、尺寸/位置和实际画面；状态问题读相关字段并做真实交互回读；接口问题读限定范围 Console/Network；有具体性能问题才使用可用的 profiling/内存/帧时工具。节点存在不等于原生合成可见，空过滤日志不等于无请求，模拟器不等于真机。GUI 扩展或 CDP 仅在能补足具体缺口时评估，不默认安装多套 MCP、重启 IDE、改账号或清存储。
6. **复用会话与已有观察器。** 现有窗口、watch、账号及存储保持。首次确认的版本/登录状态在同一会话复用；环境变化后只重核受影响边界。已知短序列可串行批量执行并共享一次就绪检查，但失败即停，保留已完成结果，不重放可能生效的操作；不把批量当同一帧或事务。若已有 `development-official.mjs` 的 batch/WXML/style/size/offset 能力，直接复用。不要为了获得另一个 socket 再启动一套自动化场景。
7. **合理放置规则。** AGENTS 的 Development execution 只保留简短入口/原则；官方 skill 维护原子调用；项目开发 skill 维护可复用操作流程；现有 development-workflow Context 保留稳定环境、归属与证据边界。优先改写过时内容，尤其 CLI/MCP 令牌混用、硬编码安装路径和已失效能力说明，不堆叠重复规则。物理设备及发布继续用既有 owner。

## 验证和边界

- 验证投入与实际影响相称。复用现有测试/证据，选支持输入、合理恢复、已知回归和重大数据风险的代表案例；不穷举主题、设备、时序或想象中的失败。
- 工具代码只跑受影响的必要验证，例如更新/无变化、本地修改保留、失败停止；不要为文档/skill 修改重跑产品构建、全量测试或已通过批次。必要时在现有已确认页面做一次只读工具核实，不重新跑产品旅程。
- 反证、变异、故障注入不是例行门槛。必要检查足够后交付；只有相关变化、实际失败或具体重要未决风险才扩大验证。
- 保持当前图像获取、像素加工及重新采用的冻结状态；保留原产品义务和 FAILED/UNVERIFIED 状态。工具优化通过不能把原生菜单、真机、云服务或图质义务改成通过。
- 不提交/push/发布/部署，不删除用户数据，不改另一台电脑。不要输出凭证或账户敏感字段。所有进程/窗口/连接操作都需明确归属。
- 按项目要求做范围明确的独立审查；审查不新增全量测试门槛。

完成后简述实际改动、以后如何自动同步/启动、做过的必要检查，以及本机仍未验证或必须人工完成的事项。需要人工动作时只列最小清单，不把可自行完成的配置工作转给用户。
