# 今晚去观星 / Starward · 系统运营控制台设计源

这是一个普通上游 Source：用于讨论独立 Next.js 受控后台、发布质量表面与轻量分享投影的系统级 UI/UX。它不是生产实现，不修改 Context、DESIGN 或 Source Plan，也不构成最终选定、验收、发布批准、备份完成或质量达标声明。

## 文件

- index.html：自包含、无构建步骤的 1440px 桌面交互控制台。七个工作区、状态模拟、危险操作护栏和本地样例下载均在单文件内。
- coverage-manifest.json：2 个 Outcome、12 个 stable control，以及 route / state / interaction 覆盖。
- README.md：本文件，记录角色、权限、危险操作、审计、回滚与样例边界。

直接打开 index.html 即可检查；所有按钮只改变浏览器内的设计样例状态，不连接 API。

## 角色与权限模型

| 角色 | 可见范围 | 可执行范围 | 明确禁止 |
| --- | --- | --- | --- |
| 地点编辑者 | 长期事实、临时实况、来源版本、模糊坐标、revision diff | 保存草稿、发起影响预览 | 静默覆盖冲突；读取不必要的精确轨迹 |
| 内容审核者 | 图片隐私扫描结果、脱敏 EXIF 类别、纠错证据、可信度 | 单项审核草稿、批量影响预览 | 在普通日志中展开原始 EXIF、精确位置或设备序列号 |
| 数据运营者 | 来源健康、延迟、成功率、缓存、许可、样例成本与作业游标 | 幂等重试、补数；发起暂停确认 | 无审计暂停来源；把 stale / partial 当作 fresh |
| 规则 owner | 同输入重放、规则 diff、预检与 owner-only 观察 | 进入 owner-only、在门满足后提升、回滚 | 绕过门禁；用单一 KPI 替代结论解释 |
| 发布 owner | release gate、技术观测、数据质量、恢复证据 | 运行预检、提升、回滚 | 在硬阻断存在时提升或显示成功 |
| 恢复演练者 | RPO / RTO、快照、验证与失败路径 | 在隔离环境发起或取消演练 | 将“快照可读”表述为“恢复完成” |
| 审计只读 | 脱敏角色、会话与动作记录 | 搜索和检查 | 执行写操作；读取 secret 或原始敏感字段 |
| 分享查看者 | 授权范围内的地点与行程摘要 | 查看、复制、下载摘要 | 编辑、查看完整 App 专业数据或后台信息 |

角色默认遵循最小权限。高风险动作还需要 owner 角色、二次确认与可恢复边界；仅拥有页面访问权限不等于拥有执行权限。

## 危险操作与批量操作

危险动作和批量变更统一遵循：

1. 先显示影响范围，包括受影响对象、门禁、数据状态与不可逆边界。
2. 明示恢复点或“无法远程收回”的部分。
3. 要求输入精确短语，或使用明确的二次确认。
4. 进入 saving / submitted-pending，锁定重复提交。
5. 返回设计样例结果、幂等键或审计 ID，并给出下一恢复动作。

覆盖地点 revision 提交、审核批量批准、作业暂停、规则回滚、发布回滚、恢复演练开始/取消与分享授权撤销。控制台不会执行真实审核、发布、回滚、恢复或撤销。

## 审计

建议的审计事件最少记录：

- 事件 ID、时间、角色、会话强度、稳定 control ID 与 Outcome。
- 动作类型、对象的非敏感标识、变更前后 revision、影响预览摘要。
- 幂等键、门禁结果、确认方式、结果状态、恢复点与下一动作。
- 错误 ID、重试次数与最后尝试时间。

普通日志不展开 secret、精确位置、轨迹或原始 EXIF；仅记录 [REDACTED]、字段类别或最小必要的模糊化信息。需要查看敏感字段时，应使用独立权限、单独审计与更短会话，而不是在通用日志里加一个“展开”按钮。

## 回滚与恢复边界

- 地点：每次提交创建新 revision；冲突保持旧 revision 生效，直到人工选择来源并确认。恢复只切回旧 revision，不删除审计链。
- 内容审核：批量结果创建 moderation revision；撤销公开脱敏版本不等于删除受限原件。
- 作业：重试、补数与恢复从最后成功游标继续，并使用幂等键避免重复写入。
- 推荐规则：草稿、预检、owner-only、观察、提升与回滚是连续状态；门未满足时提升保持禁用。
- 发布：回滚到已绑定的上一版本；候选证据与失败门禁保留，不能伪装成从未发生。
- 恢复演练：在隔离环境检查 RPO、RTO、快照、数据一致性、应用验证与敏感字段脱敏。任一关键验证失败都不能标记完成。
- 分享：撤销后旧链接不可恢复；可创建新链接，但已下载摘要无法远程收回。

## 数据状态

| 状态 | 含义 | 页面必须说明 |
| --- | --- | --- |
| loading | 数据在途 | 匹配布局的 skeleton；15 秒后显示等待过久与取消/恢复提示 |
| empty | 尚无记录 | 标题、原因、第一步 CTA |
| no-results | 查询无匹配 | 查询上下文、建议与清除筛选 |
| fresh | 新鲜度在阈值内 | 延迟、最后成功时间与来源版本 |
| stale | 超过新鲜度阈值 | 过期原因、最后成功时间、对决策的限制 |
| partial | 仅返回部分范围 | 已返回与缺失范围；禁止当作完整结果 |
| degraded | 使用受限回退 | 回退来源、时限、不可回退类别 |
| error | 请求失败 | 可知原因、输入保留、重试与三次失败后的支持路径 |
| disabled | 权限或门禁阻止 | 禁用原因与获得权限/解除门禁的路径 |
| saving | 写入样例状态 | busy 状态、重复提交锁与取消/恢复上下文 |
| success | 本地样例结果 | 明示“设计样例”，并给出下一恢复动作 |
| edge | 极端内容或规模 | 10,000+ 行、长文本、缺失字段和混合书写方向不破版 |

## 样例数据与边界

- 所有地点、数值、时间、成本、来源名、revision、规则版本、审计 ID、错误 ID、会话与运行结果均为“设计样例数据”。
- 来源名为匿名占位，不映射真实生产供应商；页面不声称任何真实授权、SLA 或成本。
- 预检、owner-only、灰度、提升、回滚、备份、恢复、审核和分享撤销只做本地交互演示。
- 分享投影仅承接行程/地点链接的查看、复制、下载和授权状态；不复制完整 App 的专业预报、模型对比、后台 revision、规则或发布控制。
- 未包含生产 Next.js / API、认证实现、真实数据合同、真实下载格式、Figma 迁移、Context / DESIGN 更新、Source Plan 修改或最终验收。

## 键盘与无障碍

页面使用语义 landmark、表头 scope、原生表单控件、可见 focus-visible、44px 主要触控目标、状态文本与 ARIA live region。颜色不是唯一状态提示；边框语法、文本标签与原因同时存在。支持 reduced motion；文本放大时工作区可独立滚动，危险确认使用原生 dialog 并可用 Escape 退出。
