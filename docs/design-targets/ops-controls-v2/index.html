把页面原型拆成可实现、可验证的控件契约

这份大设计稿保留 v1 的成熟三栏图谱方向，但把每个稳定控件提升为真正的工程交付目标：中央不是通用状态面板，而是控件自己的交互 specimen；右侧不是装饰注释，而是 Visual、States、API & Logic、Motion、A11y、Assets 与 Acceptance 的实现检查器。上游 coverage manifest 继续独占稳定身份、顺序、route 与声明 states；本项目的 implementation-contract.json 独占控件级开发契约；HTML 只负责把契约投影成可操作样本，避免产生第二份实现权威。
