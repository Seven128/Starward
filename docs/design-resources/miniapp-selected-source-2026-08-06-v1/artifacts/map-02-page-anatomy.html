02 · 所有权清晰

层级与手势分区

绝对定位仅用于有边界的地图内叠层。操作层永远高于业务叠层；弹层封闭焦点和阅读顺序；Toast 不承载必须恢复的错误。

03 · Reflow contract

响应式与大字规则

下面是实现约束，不是第二套页面方向。320/375/430 都保留同一信息架构和操作顺序。

宽度横向滚动换行 / 重排固定边界永不发生
320px仅快捷筛选带标题、状态、值/单位可换行；选点卡压力时内部滚动44px 触控、顶部胶囊、底部安全区、地图手势区不压缩触控；不裁切主操作
375px快捷筛选带；Sheet 内容纵向滚动长中文自然重排，三列数据保持值/单位语义16px 页边距；12px 地图紧凑边距不出现整页水平滚动
430px仅当筛选超出时保持一列，不添加新产品区块可读宽度与同一 z-order不拉伸卡片到遮挡浮动控件
系统大字筛选带仍横向滚动关键文本不限单行；状态/恢复动作始终可见值与单位分离；主要 CTA 至少 44px 高不 line-clamp 决策与警告

28rpx · 14px标准卡片 padding / radius-md
