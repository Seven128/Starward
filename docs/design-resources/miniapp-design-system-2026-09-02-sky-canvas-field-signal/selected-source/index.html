01

设计原则

像轻量、可信、有户外生命力的决策仪器；用秩序承载密度，不靠装饰制造情绪。

  1. 01

    结论 → 行动 → 证据

    先回答今晚是否值得出发，再组织地点、窗口与安全行动，最后按需展开专业依据。

  2. 02

    日光中性，户外信号

    大面积保持轻中性；活力只来自路线、时间、天象和风险的可读信号，不来自深蓝容器或装饰星空。

  3. 03

    共享轴承载高密度

    云量、透明度、视宁度和事件共享时间列；使用行、带、轨与矩阵，不把指标拆成卡片。

  4. 04

    局部两种强调色

    一个局部最多两种非中性色，警告/错误按需加入；颜色始终有唯一语义所有权。

应当

  • 平静、具体、可执行
  • 状态同时有文字、形状或线型
  • 示例数值明确标记为演示数据

禁止

  • 卡片套卡片、每指标一卡
  • 渐变光晕、玻璃拟态、循环装饰
  • 绝对晴朗、保证可见等无依据承诺

无障碍与适配

可访问性是组件合同的一部分，不是交付后的补丁。

88rpx / 44px

触控目标

可见控件可为 56–60/68–72rpx，最终承诺为 92–96rpx；实际命中区仍至少 44×44 CSS px，且相邻扩展区不重叠。

Tab / Arrow / Esc

键盘

所有交互可到达；分段控件支持方向键；Escape 关闭 sheet/dialog。

touch / keyboard split

视觉焦点

触摸按下后不保留焦点框；文本编辑用光标与 1px 浅变化。仅外接键盘/桌面/辅助键盘用内侧下边缘 focus-visible；pointer: coarse 不持久显示。

200%

放大文字

长中文按钮与字段标签允许换行；数据值可保持一行，但标签列加宽或上下重排。
