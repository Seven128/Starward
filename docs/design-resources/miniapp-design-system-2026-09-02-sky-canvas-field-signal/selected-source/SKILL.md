Read `README.md`, `DESIGN.md`, `tokens.scss`, `colors_and_type.css`, `context/provenance.md`, and the relevant file under `preview/` before generating or revising an interface.

## Required use

1. Treat the package as an **unselected candidate**, never current project authority or production conformance.
2. Preserve conclusion → action → evidence and existing route/state responsibilities.
3. Exclude all map concerns, native App, and owner-operations surfaces.
4. Consume semantic roles from `tokens.scss` / `colors_and_type.css`; do not hardcode a second palette.
5. In one local region, use at most two chromatic accents besides warning/error.
6. Observation mode is separately authored pure black + warm red. Bind the complete target theme before painting and never flash blue, white, yellow, green, or neutral gray.
7. Dense evidence uses shared axes, rows, bands, tracks and matrices; never one card per metric.
8. Use the four-layer whitespace grammar in `DESIGN.md`: screen/layout, group rhythm, component-internal breathing room, and visual-weight whitespace. Compact layouts must not visually fill the 88rpx target.
9. Separate visible geometry from hit geometry: compact 56–60rpx, ordinary 68–72rpx, final commit 92–96rpx; every interactive target remains at least 88rpx and adjacent targets never overlap.
10. Use the fixed 14-family semantic taxonomy. Chip appearances belong to Checkbox/Radio; Tabs and Segmented are Choice Bar subtypes with one moving indicator.
11. Touch does not retain a focus frame. Text editing uses caret plus a subtle 1rpx tonal edge; `:focus-visible` is only an external-keyboard/desktop/assistive fallback and never draws a full outer frame.
12. Switch uses a 92×48rpx visible track, 40rpx thumb, 4rpx inset and 44rpx travel inside an 88rpx setting row; on is Trail Green.
13. All motion is causal, interruptible and reduced-motion aware; Choice Bar selection uses a single transform-based ~160ms indicator and never per-item flashing borders.
14. Mark preview values as demonstrations unless the artifact is wired to authoritative live data.

Before handoff, run `verify.mjs` and inspect the affected preview. Do not introduce external network assets.
