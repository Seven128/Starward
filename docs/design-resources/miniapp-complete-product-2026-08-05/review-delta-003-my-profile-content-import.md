## 1. User feedback, preserved verbatim

> 我的页面族上面的tab栏，我的收藏计划设置这里滚动条出来了，像是个bug。我的页面里面观测计划这个卡片不要。官方示例文章也删掉。我的里面可以设置个人主页链接，例如小红书，微博视频号等等。支持导入我在其他平台发布的观星帖并编辑新增关星地点。

`新增关星地点` 按上下文规范化为 `新增观星地点`，不改变用户意图。

## 2. Normalized pending requirement

### 2.1 顶部页签不出现原生滚动条

- 顶部页签仍为 `我的 / 收藏 / 计划 / 设置`；本轮意见没有删除 `计划` 页签。
- 默认中文字号和 320/375/430 宽度使用四等分页签，完整显示且不产生水平滚动条。
- 大字模式下允许自适应为两行 2×2，但仍保持一个语义 `tablist`、稳定焦点顺序和当前项，不允许隐藏不可达页签。
- 页签触发器至少 44px 高，选中态不只依赖颜色；切换时恢复每页独立滚动位置。

### 2.2 精简“我的”首页

- 删除“我的”首页中的 `观测计划` 摘要卡片。
- 删除“我的”首页中的 `官方示例文章` 卡片。
- `计划`页及相关能力暂时保留；`攻略/文章`能力也保留在点位详情和内容路由中。此次删除仅作用于“我的”首页卡片。

### 2.3 个人主页外部链接

- 用户可在个人主页设置多个外部平台主页链接，候选平台包括 `小红书`、`微博`、`视频号` 和 `其他平台`。
- 每项至少包含平台文本名、主页 URL/账号展示值、公开范围、编辑、排序和删除。
- 不伪造平台 Logo；使用统一外链图标加平台文字。
- 外部平台打开能力可能受微信小程序、业务域名和平台策略限制。候选必须提供 `复制链接` 回退，并把“可直接打开”标为运行时能力，不作无条件承诺。
- URL 输入包含协议/长度/危险 scheme 校验、重复提示和隐私说明；私密或仅自己可见链接不能出现在公开个人主页。

### 2.4 导入其他平台发布的观星帖

用户可从“我的”发起 `导入我的观星帖`：

1. 选择来源平台：小红书、微博、视频号或其他。
2. 粘贴分享链接；若平台解析不可用，可切换手动导入标题、正文和媒体。
3. 确认“这是我有权导入和编辑的内容”，并保留原平台、原链接和导入时间。
4. 显示解析状态：处理中、成功、部分成功、不支持、链接失效、私密不可读、限流、网络失败。
5. 进入可编辑草稿，允许修改标题、正文、媒体、来源说明和可见范围。
6. 关联已有观星点，或提出 `新增观星地点`。新增地点进入点位投稿/审核流程，不因一次导入直接成为正式观星点。
7. 保存草稿、预览和提交；导入失败不能清空已经手动编辑的内容。

### 2.5 来源、权利与安全

- 候选不声称已获得小红书、微博、视频号 API 或抓取许可；自动解析属于 `decision-required / capability-dependent`。
- 服务端不得由用户 URL 任意抓取内网资源；最终技术方案需规定 URL allowlist、重定向、大小/类型、超时、恶意内容和 SSRF 防护。
- 导入媒体继续执行 EXIF/GPS 清理提示、来源/版权确认、审核、删除和申诉状态。
- 导入内容的原平台来源持续可发现；编辑后不伪装成平台官方内容。

## 3. Interaction and accessibility consequences

1. 顶部页签在默认和大字组合下无文档级横向滚动、无可见原生滚动条、无低于 44×44 的可点击目标。
2. 外部主页编辑使用可恢复的 Sheet/页面；关闭前有未保存提示，保存成功后把焦点返回触发器。
3. 导入流程有明确步骤、返回路径、草稿保存和中断恢复；每个错误状态提供手动导入或重试。
4. 平台只能通过文字与统一图标识别，不能只靠品牌颜色。
5. 链接、来源、权利确认、点位关联和坐标敏感性具有明确辅助技术标签和错误关联。

## 4. Non-global replacement rules

- 不删除 `计划`页签或计划详情；只删除“我的”首页的观测计划摘要卡。
- 不删除攻略/文章系统；只删除“我的”首页的官方示例文章卡。
- 不把所有外链都承诺为可直接跳转；保留复制链接与能力受限状态。
- 不把导入帖中的新地点直接写成正式观星点；必须经过已有点位关联或新增点位审核。
- 不制造或临摹小红书、微博、视频号 Logo。

## 5. Product/technical implications held pending selection

- 原产品方案“我的”页面、个人主页、内容贡献、Demo/商用能力矩阵和验收文本需要在最终选定后加入外部主页链接与内容导入。
- 技术方案需要外部主页 link model、归属/可见性、URL normalization、安全校验、内容导入 job、adapter capability、解析状态、幂等、媒体复制/引用、来源 lineage、草稿恢复与点位审核关联。
- 各平台允许的导入方式、API/授权、域名和深链能力均为 `decision-required`；候选提供能力检测和手动降级，不定义未经证实的接口。
