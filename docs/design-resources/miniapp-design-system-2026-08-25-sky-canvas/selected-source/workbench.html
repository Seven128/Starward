紧凑选择态

字体与胶囊保持轻巧；选中时大号月光星从右上角被圆角裁掉一部分。hover 不生成额外外框，键盘 focus 紧贴可见胶囊。

选中反馈是多通道的

星角、边线、文字与 aria-pressed 同步，不只依赖颜色。

真实图标资产

通用图标来自本地 Lucide Static 1.33.0；DRA 文件内没有每屏手工绘制的 SVG。生产仍通过 semantic-asset adapter，不直接让页面依赖文件名。

目标尺寸与输入

可见图形可以紧凑，完整点击目标至少 44px。pointer hover 不扩张几何；keyboard focus 使用贴合可见图形的双环。

开发消费映射

这是实现入口提示，不把 DRA 静态页面伪装成生产契约或验收。
