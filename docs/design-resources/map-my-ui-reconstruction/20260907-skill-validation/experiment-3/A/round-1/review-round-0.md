## 实际发现

- A2 地图的日期文本从 y=694 开始，而文档裁切止于 y=708，确实只露出半行。A3 天文标题可完整看见，时间从 y=708 开始位于裁切后；A1 的天文信息整体在裁切后，符合一份文档的 medium 状态。
- A1 资料入口命中矩形底边为 y=709，原裁切止于 y=708；文字完整，但完整命中范围差 1px，需要连同视口边界修正。
- A2 我的页索引列 70px，造成“现场反馈与纠错”拆成两行，且导入副文案被显式换行；比其他两方向更占高度，未形成合理的密度收益。
- A1/A3 我的页账户为 18 Medium、计划地点为 16 Medium，虽然不是同级尺寸，但字重一致，计划在小块区域里仍有较强标题感。根据用户对层级与整体尺度的反馈，本轮把计划地点降为 15/22 Regular，账户保持 18/26 Medium。
- 线性 SVG 原来采用 resize，框尺寸缩小但描边未同比变化，实图偏重；云观星还误选了望远镜主题场景 SVG，表现为与其他线性图标不一致的蓝色实体。

## round-1 的改动

1. A2 天文标题与唯一所选日期/时间排在同一 44px 入口带；不增加或复制时间。它们在原生文档中仍按标题→时间顺序。后续缺失切片与指标保留在裁切后。
2. A1/A2 文档视口加 2px，底部操作区随之下移 2px；不改面板整体高度、地图或固定裁切，使资料入口保持完整 44px。A3 保留原边界，避免露出下一行像素。
3. A2 我的页索引列改为 104px，保留完整单行职责标题；取消导入人为换行，草稿与审核状态同行。计划/反馈/常规条目的高度分别调整为 90/76/70px。
4. 三方向计划地点统一为 15/22 Regular。A1/A3 计划行各压缩 12px，保留全部日期、地点与准备事项。账户标题继续是 18/26 Medium，业务入口 14/21 Medium，副文案 12/18 Regular。
5. 图标使用原生 `rescale` 保持几何与描边比例。云观星采用共同资产中的线性 Lucide telescope.svg，不再使用主题场景 artwork；其余已有模式图标继续优先。
