# A 组独立方向说明

本稿只读取 experiment-3 指定的共同输入、当前项目约束、字体探针、图标及公共机械 API。没有读取新的资源 Skill、其他候选或历史评审，没有执行 Figma 或修改生产。首次实现尚待实际 PNG 回看。

## 三个方向

- **清晰分区**：地点身份用 20/28 Medium 建立锚点，开放状态为唯一轻底分组，设施两列比较。我的页把计划与反馈置于一组连续边界内，日程、地点和准备事项分三级，链接与导入作为安静的下一级入口。
- **资料索引**：地点与区域同行；开放、设施采用窄标签列与宽事实列。我的页用固定索引列关联图标和职责，右列排列实际记录，产生明显不同的资料册阅读节奏。
- **连续清单**：地图以小图标串联开放与设施事实，不为每个事实加卡。我的页仅计划与反馈共享一块轻中性面，下面的链接与导入继续使用带分隔线的紧凑列表。

## 候选字级与几何

这里提出局部视觉候选，不回写根 DESIGN.md。正文从 15/22 调整为 14/21，搜索从 16/23 调整为 14/20；地点身份仍 20/28，账户标题 18/26，计划地点 16/24，普通入口 14/21，来源、日期及次级状态 12/18。所有字体来自真实 Noto Sans SC Regular / Medium；没有把 Medium 描述为 600，也没有使用不存在的 SemiBold。未使用 Bold，以避免和现行禁止普通界面 700 的约束冲突。层级主要由标题与内容的尺寸差、组间距、语义对齐建立。

图标可见 16/18/20px，普通图标底板 28/32px。所有业务交互包装至少 44px，图形不随命中区同步放大。地图三个方向共享 430px medium 面板高度（390×844 时），比基线 clamp 得出的约 473px 略低，为固定地图参考的点位与归属留出空间；不缩放页面或删业务。所有方向顶部保留 44px 系统区与 44px 微信区，底部导航 44px 加 34px 安全区。

## 内容、布局和素材边界

三档对应同一原生文字/Auto Layout 文档。本轮只生成 medium，后续天文内容保留在裁切区下方；没有把时间或天气复制到独立卡片以填首屏。天文日期、21:00、24%、26°C、2.4 m/s、月光影响较弱、20:40 均来自共同 fixture。fixture 未提供真实可拖拽的离散切片，因此不伪造邻近时间刻度；本轮原生可编辑日期控件保留 `time` key，但真实 ruler、拖拽和数据联动未验证。图层处于关闭状态，图层互斥和三选项实现仍属后续状态范围。

开放时间、停车与厕所明确待核实，夜间能否进入显示暂无数据。地图是共同 390×480 未调色 OSM 原图，放置于 y=88，marker 锚点相对图片为 (195,209)。© OpenStreetMap 贡献者在可读白底上保留；外壳应链接 https://www.openstreetmap.org/copyright 并说明 ODbL。不能据此证明腾讯 native map 的外观或命中。

原生图标组件源位于自有 root 右侧裁切区域，产品稿内使用可编辑实例；图标来自给定 ISC 词表，不重画图标系统。文字设置真实行高及 HEIGHT reflow，横向 Auto Layout 使用固定主轴宽度和自动交叉轴高度，纵向使用自动主轴高度和固定交叉轴宽度。
