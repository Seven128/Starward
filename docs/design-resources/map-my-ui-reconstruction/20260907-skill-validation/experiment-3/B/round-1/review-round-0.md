## 地图共同问题

- 三图概览下划线出现在天文右侧：rect 被当作横向 Auto Layout 的第三项。资料入口右端短线同源，分隔线成为第四个 flex 项。round-1 对放置在 Auto Layout 父级中的定位装饰矩形显式设置 `layoutPositioning = ABSOLUTE`，其 x/y 现在由意图坐标持有。导航选中线源组件内几何保持不变。
- 三图路线图标与开放信息贴左甚至裁边：`basic.layoutAlign = CENTER` 没有使纵向文档里的固定宽子容器居中。round-1 使用文档父级的 `counterAxisAlignItems = CENTER`，正文获得与身份相同的对称 inset。
- 搜索文字正中形成像大按钮的阅读暗示，round-1 改为同一字段左对齐，14px 起始内边距、9px图文间隔，44px完整触控不变。
- 云观星采用的 semantic telescope-day 显示成较重蓝色实体，round-1 改用共同 assets 中现有 Lucide `telescope.svg` 线性几何并用 skyStrong。未生成新图标，也未改地图图片。

## 三方向整体回看

1. 现场手册：账户身份与普通入口层级已经分开，计划仍有两个同样重的正文行，日期另占一行且图标落在段落中部，造成计划块偏高。round-1 将日期并入计划标题行；目的地14/20、准备说明12/18纵向关联，语义图标对齐标题。资料表面和共享分隔保留，减少约一行的无效占高。
2. 静线条目：18 Bold 账户/地点身份与14 Regular内容的分级在原图可见，但地图没有实现正确内容轴，削弱了整个方向。修复地图后保留条目式日期/目的地关系，避免重新设计成另一方向；我的图标改为顶对齐，状态紧邻自己的标题。
3. 出发索引：日期/目的地横向关系能区分于其他两稿，但账户到计划的间距较松。账户行从78降为66，实用组到常规入口间隔从24降为18；固定真实日期的分解与层级不变。

所有我的页：蓝色实体头像替换为共享 `user-round` 线性账号语义，34px安静中性底板和单一44px设置gear保留。各入口图标对齐文本开头，避免长单元的图标落在中部；箭头仍归属于整行动作。
