# B round-0 实图回看及 round-1 修订

已逐张以390×844真实导出查看 `round-0/e2-B-{1,2,3}-{map,my}.png`，并读取同轮 Plugin API JSON。没有查看其他组或旧试验。

## 实际观察

- 六图的账户/地点身份已高于普通内容，正文占高也比所有行标题化更克制；不过仅用Medium，强身份仍不够明确。round-1仅身份与方向二重点计划对象改用已实测可用的 Noto Sans SC Bold，数值700如实记录，不冒充600。
- B1 我的计划区域96px，计划细项末尾与分隔线之间空白偏多，反馈行也比实际两行文字宽松。减为80px计划+60px反馈，账户头74→66。保留所有事实、独立行及同一utility表面，整块减少约30px。
- B2 我的129px计划区域对三条事实偏大，标题与地点仍有接近风险。收为106px；页面身份20/Bold，计划对象17/Bold，计划标签12/Regular/语义色，准备说明13/Regular。反馈77→67，后续常规入口保持64。预计主体高度减少33px。
- B3 我的把两个计数拆为整块107px，视觉上看似稀疏统计卡，不符合用户希望。此次正式重组为共享136px utility表面内并排的两个任务：左侧计划对象/日期/准备；右侧现场反馈的草稿与待审。两项都是完整独立可点击区域，竖分隔只表达职责边界。原utility约213px，减少约77px，新增留白不填假功能。
- 三张地图因同一参考图和同一业务文档顺序，差异天然有限。B3身份改为地点名与区域同一行，身份52→34，medium顶部430→448以释放18px地图面积；字段矩阵仍保持场地/设施共享对齐。B1保留连续记录；B2保留区域优先和绑定未知事实的浅金带。没有通过重排天文或造天气卡制造差异。
- 可见瑕疵：微信胶囊内分隔线因旋转向上伸出，修为原生1×14矩形；云观星语义SVG重染后呈实心不清楚，改用共同词表内已有Lucide telescope轮廓几何。它们是技术修正，不算独立设计增益。

## 几何与诚实性

实际快照中，每张地图16个可见标记控件、我的7个可见标记控件，宽高均≥44。资料三分栏接缝有浮点精度约0.00002px相交，round-1改整数宽与2px间距，避免检查器舍入差异。没有实际面积重叠。地图medium底部的场地资料/观星攻略/数据来源44px区域完整，天文与time在同一保留文档裁切外，不能算当前可见控制；没有把它们隐藏到另一棵树。
