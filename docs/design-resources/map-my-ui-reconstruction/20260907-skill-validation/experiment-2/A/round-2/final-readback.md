## A3 time 控件的严格全框限制

以最终 A3 地图 root 局部坐标计算，完整 `Curved time ruler — discrete slices` 框为 **x16、y631、358×78px**，底边709。父 `Medium viewport; scroll only at large` 为 **x0、y398、390×304px**，底边702。

两者相交后的有效可见矩形为 **x16、y631、358×71px**，即完整框底部 **7px 被裁切**。21:00 Text 为 **x171、y673、48×22px**，底边695，在viewport中完整可见；这里的有效可见时间区两个维度均大于44px。

通用 check-resources 要求整个control框位于裁切边界内，因此仍报告A3 time严格全框问题。该检查能发现容器外框被截的事实，但不区分“单文档medium允许截取后续内容”与“文字/有效目标不足”；有效矩形足够也不能反向证明完整控件框无裁切。这条告警保留为明确的资源限制，不作为通过项抹除。

只有静态 Figma 原生节点和几何可见性证据。没有验证 medium中时间控件的真实响应、拖动手势、截断后语义命中、large滚动、真实切片更新或WEAPP可交互性；fixture仍只提供21:00。后续生产采用必须按实际owner合同验证，不能拿71px可见高度证明真实交互可用。
