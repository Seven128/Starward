## 三种方向

1. **清晰分组**：地图开放说明与路线同排，停车和厕所共享双列；我的以共享浅中性区域收纳计划与反馈，主页链接和导入用平面条目。用少量容器边界让关联事实一次扫读。
2. **平静清单**：地图以固定标签轴呈现开放与设施，夜间进入条件连接路线入口；我的把计划与反馈放在一个双栏共享区域，日常内容回到纵向条目。横向比较只用于短且相关的既有信息。
3. **轻量索引**：地图把地点图标与身份并列，以到达标题及连续正文组织缺失事实；我的采用单一连续列表、统一图标轴和分隔线。最少容器，靠稳定对齐与节奏区分内容。

三方向均保留同一地图裁切、同一客观文档顺序、仅地图/我的主导航、单一设置 gear、同一文档章节定位、固定三动作。方向差异来自内容排布；没有新增功能或假造商业模块。
