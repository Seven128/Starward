## 不是本轮拟议变更的内容

- 不增加第三个主目的地，不恢复旧详情/夜间/专业/收藏父页，不把星图或出发推荐放回地点信息面板。
- 不改变正式点位资格、授权、数据来源、时间真源、提交审核、贡献身份隔离、链接权利/导入流程或服务端发布边界。
- 不新建视觉 token 真源。当前小程序 `DESIGN.md` 中 body 15/22、body-secondary 14/21、action 14/20、target-min 44 等继续为基线；此轮 Figma 自有坐标和字体只是候选资源。若采用时发现不同值，先逐项提出具体差异和理由，由 owner 决定，不能反向修改根 DESIGN 来掩盖偏差。
- 不引入新的图标家族/运行时 CDN，不把示例资产当真实 provider/合法媒体证明。Map 底图不属于本轮重绘权威。
- 不恢复已退役的设计绑定门禁，不要求普通生产 UI 必须同步 Figma；本次 Figma 来自用户明确要求的资源实验。

## 采用后的最小实现与验证范围

只有用户选定方向后，才在当前 `features/my/my-library-page.tsx/.scss`、相应 Map/spot-panel owners 与现有共享组件中实施确认的表达。先保留鉴权、缓存、stale/refresh error、日期选计划、真实贡献数量、navigationPending 与失败恢复，再调整布局；不复制一个候选页面树或数据 store。

重点补查账户返回滚动和 opener focus：当前代码常驻和刷新不等于该契约已经落实。地图的 edge/system Back、章节焦点与连续 motion 也不能从静态稿或函数名称推断通过。采用后按 `interaction-spec.md` 在同一个 WEAPP 候选上完成 44px 命中、四屏宽重排、三主题连续运行、真实 frames 和手势/返回检查。

用户盲评/主观有用性、手机实际阅读、原生拖动与白闪继续独立记录。两行文字或相同 PNG hash 只能支持相应资源结论，不代表方向已选定、生产已符合或整轮实验已通过。
