# 第一轮匿名方案被拒后的设计诊断

## 事实、范围与结论边界

主任务转达的用户原话是“都不满意...”，并明确说明六个匿名候选均被拒绝。用户没有在本次反馈中给出具体原因。以下是独立评审者基于已逐张看过的初稿、最终稿及最后局部修订图，对可能原因的分析，不能作为用户原话或用户动机。

本诊断不重新评分，不新增样本，不覆盖原评审，不把后续方法改进解释为本轮获准。原六个候选仍保留为这一轮被用户拒绝的结果。已有辅助视觉分只描述局部表现，不能抵消此次拒绝。

证据范围为匿名评审页、共同 brief 和已经实看的 PNG；未读取分组、作者稿、私有映射、设计生成方法。手机、真机和动态行为仍未测。共同 brief 固定了地图素材及裁切、示例数据、两个主导航和主要交互语义，因此共用地图本身不是方向缺乏差异的证据；可分析的是这些固定约束之外仍然采用了怎样的构图、组织和强调。

## 1. 六个候选主要在换容器，方向差异没有充分进入阅读结构

**图片事实。** 地图页全部延续同一种顺序：顶部搜索和右侧两个悬浮按钮，下方白色圆角面板，地点名、地区、概览／天文、开放与设施状态、路线／资料／来源，底部三个动作及主导航。面板起点主要集中在约 y330 或 y386 两个高度。变化集中在未知设施是双栏、表格还是灰卡，地点是否带图标，以及部分按钮有无底色。

我的页全部是上方账户，下方相同的四项内容，再接较大留白与底部导航。611dc7ca 把计划和反馈并排；6a160862 将两项上下装进灰卡；ae826207 把计划做大并将反馈计数拆成两列；7d6789e0、f6f45c38 使用紧凑列表；68bcf17c 引入日期边栏。这些变化存在，但没有明显改变用户第一眼看什么、下一步先读什么的整体组织。

**诊断推断。** 这更像同一布局的多种包装，很难让用户感到是几条有不同取舍的产品设计方向。特别是地图这一主要场景，六张图的轮廓和视觉重心高度接近。几种灰卡和列表形式本身也不足以建立跨两页的完整设计语言。

**限制。** 不能为追求差异改变正式 marker、单文档章节定位或三个主要动作的语义。应在允许变化的阅读层级、内容关系、空间分配和视觉节奏上建立差异，而不是通过破坏交互合同制造不同。

## 2. 地图占据最强视觉注意，面板内没有形成同样明确的决策重心

**图片事实。** 所有地图都使用同一张色彩、道路和地名丰富的地图参考；面板则大部分是白底、灰字、细分隔线和小面积强调色。地点名是最明确的大文字，但其后主要呈现开放／停车／厕所待核实、场地资料和数据来源。68bcf17c、7d6789e0 的最终图仅在接近底部动作栏处露出“天文信息”及时间；其余最终图在当前裁切内没有露出该段正文。

**诊断推断。** 画面能让人知道这是哪里，也能提醒现场信息未知，但“今晚去观星”作为产品的当前任务，没有在面板里获得很清楚的阅读中心。面板更容易被读成一般地点资料摘要。它目前把不少有限空间分配给未知事实和通用资料入口，用户可能需要展开之后才看到更能帮助判断今晚安排的信息。

**限制。** medium 未露出天气正文不是已证实的业务缺失，也不代表应该把天气硬塞成独立卡片。共同 brief 允许同一文档裁切，且禁止另造推荐窗口或面板星图。需要重新考虑的是当前裁切的阅读引导和事实优先级；是否应改变章节内组织，应先确认 owning contract 允许，而不是凭截图擅改文档语义。

## 3. 信息密度不均：局部被压缩，别处的空间却没有承担明确作用

**图片事实。**

- 611dc7ca 我的页把较长的计划内容压在半宽卡内，日期、地点和准备说明分行；内容约到 y506 结束，其后到导航仍有较大空白。
- ae826207 我的页约 y192–443 的大卡只承载一次计划与两个计数；“草稿／1 条”“待审核／2 条”各拆成两行。
- 6a160862 地图页的停车、厕所各重复写“待核实”和“暂无数据”，用两行表达同一个未知状态。
- 多张地图页在地点名与章节之间、资料入口与操作栏之间保留较明显间隔，但 medium 内仍只能看到少量实质内容。
- 7d6789e0、f6f45c38 的我的列表已经较紧凑；它们证明这批图的密度问题不是“所有地方都太松”，也不应该统一减小全部间距。

**诊断推断。** “小巧、有效信息密度高”没有稳定转化成空间分配原则。部分方案用灰卡和双栏表现分组，却付出了换行、重复标签或计数占高的成本。局部局促与下方留白并存，会让布局显得由容器样式驱动，而非由内容长度和阅读任务驱动。

**限制。** 四项业务本来就不需要填满屏幕，下方留白本身不是缺陷。不能用虚构统计、营销文案或装饰来填空。应把空间还给需要阅读的内容，减少没有增加理解的拆行和重复，并保留有目的的留白。

## 4. 视觉层级主要依靠容器和少量颜色，关键关系缺乏充分表达

**图片事实。** 这批图反复使用白底、浅灰卡、淡色图标底板、深灰标题、灰色辅助字、紫色选中态和细线。两页中多数内容使用相近的标题／说明节奏，计划与反馈常因放在同一卡内获得同级视觉权重。路线按钮有时获得独立绿色底色，地点的待核实信息、场地资料及数据来源则紧邻排列。

**诊断推断。** 各种组件本身规整，但还不足以让“当前计划”“状态待处理”“资料入口”等不同角色在阅读时产生明确区别。设计的简约较多体现为低饱和、白底和少装饰；精致感所需要的取舍、比例和关系表达没有同等清楚地建立。因此即便消除了漏点、裁字和间距错误，用户仍可能认为整体没有形成成熟的产品方案。

**限制。** 不能把“高级感”简单等同于更强品牌色、更多阴影、更大的标题或新增装饰。这里的缺口是视觉强调是否对应内容角色，以及两页是否共同遵守这套关系，而非缺少某种潮流外观。

## 5. 图标和点击外观基本齐全，但比例与语义关联还停留在逐项配齐

**图片事实。** 所有地图页都配齐了搜索、定位、图层和底部动作图标。部分候选的地图 marker 与定位按钮都采用相近的靶心图形；部分我的页混用日期边栏、文字侧标和淡色图标。611dc7ca 的计划／反馈缺少下方两项同样的方向箭头；ae826207 的计划是无图标的大标题区，反馈及后续入口又有图标。初稿曾出现搜索或动作图标远离文字，最后虽已修正，仍能看出原先图文关系没有作为一个整体稳定处理。

**诊断推断。** 图标更像每项内容的附属标识，没有始终用一致的比例、对齐和语义区分来支撑阅读。地图上面积明确的白色悬浮按钮与面板中较轻的图文入口之间，视觉权重的选择也没有跨候选体现出不同且自洽的意图。业务图标增加了一致的表面样式，却不必然使业务关系更清楚。

**限制。** 静态图不足以证明实际命中区域不合格，也不能据此断言所有图标都太小。应区分图形可视大小、按钮底板大小和实际命中范围；无需为了显得精致而统一放大图标。优先解决图标与文字的成组、入口的一致提示和不同角色的可辨认性。

## 可转化为设计 Skill 改进的四条原则

1. **先检验方向差异是否改变了阅读体验。** 在写布局前，用简短语言说明每个候选优先帮助用户注意什么、如何组织已有事实、为此牺牲了什么。若几个候选只是在改圆角、卡片边框、双栏或图标底色，应继续推敲，不能把它们算作已形成不同方向。无需固定三套模板或制造正式设计文档。

2. **从完整内容和当前视口安排空间。** 用共同 fixture 的真实长度检查每个区块为什么存在、占高是否值得、是否重复表达。避免先选卡片样式再压入内容；保留有用留白，同时解决局部拥挤。不得为密度硬塞当前文档状态之外的控件，也不得用虚构内容补空。

3. **把视觉强调绑定到内容角色，并跨两页复用。** 标题、正文、状态、入口与主要动作应有可解释的比例和强调关系；验证这套关系在地图与我的两页都成立。图标与文字作为整体检查，区分可视大小与命中大小。不要把低饱和底色、浅灰圆角卡和图标底板当作精致感的替代品。

4. **先看整体是否成立，再清理局部错误。** 第一次实际 PNG 审视先判断构图、重心、信息组织和方向差异；如果只能提出“修黑点、对齐箭头、调几像素”一类意见，应再问整体是否值得继续。局部修复不会自动解决整体不被接受的问题。辅助评分与用户接受状态分别记录；用户拒绝后保留失败样本和原评分，下一轮以新方案验证方法，不用回写分数证明旧方案成功。

这些原则不要求新资产、装饰性 hero、营销叙事或更换业务模型。本轮最需要改进的是设计判断与对实际整体结果的审视顺序；这是评审者的诊断，不是用户已经确认的拒绝原因。
