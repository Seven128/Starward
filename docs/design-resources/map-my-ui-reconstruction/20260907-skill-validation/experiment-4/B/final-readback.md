# experiment-4/B 最终实图核对与冻结

最终设计为 `round-2/design.js`，对应 `round-2/e4-B-{1,2,3}-{map,my}.png` 和同名 JSON。已逐张使用 view_image 查看全部六张最终真实导出。两轮正式设计修订已用完，冻结本组，不再修改设计。原始稿、round-0、round-1及回看记录保留。

## 最终观察

- B1 Map：地点身份、访问事实、设施、证据入口和固定三动作可读；地图归属明确；天文没有在medium边界露出残片。B1 My：计划地点和日期/准备关系比初稿更紧凑，反馈保持在同一共享浅底，账户标题与条目/状态有明确字号和字重差异。
- B2 Map：开放/设施键值轴易扫读，静态画面没有发现新的可见裁切。B2 My：日期列与计划内容关联清楚，草稿/审核和主页链接计数退居说明。该方向仍是作者倾向继续验证的候选，状态仅为 recommended-unapproved。
- B3 Map：区域先于地点名、开放事实紧邻路线的结构保留。B3 My：两项职责的图标/标题已同行，标题与首条内容的垂直起点现在对齐，双列任务对照关系比round-1清楚；左侧多一条准备说明来自真实内容长度差异，无需在右侧编造字段补齐。个人内容入口仍在任务组后。
- 全部自有图标以线性几何与受控语义色表达；头像和云观星不再表现为蓝色实物色块。三组地图方向差异仍较克制，My方向差异更明显；固定职责、固定参考底图和medium裁切的限制如实保留，不据此宣称具有强烈品牌辨识度。

## round-1 到 round-2 差异证据

对六对真实 PNG 执行 SHA256 比较：B1-map、B1-my、B2-map、B2-my、B3-map 的PNG文件字节相同；B3-my不同。最终逐张观察与该结果一致：可见设计变化位于B3 My右列标题与内容起点。该证据只针对本次导出的这六对文件，不扩展为所有未来导出的绝对像素不变保证。
