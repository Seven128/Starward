# 两次独立复验

原测试方案4.3要求冻结后再完成两次独立成对试验，且不要求用户再写提示词。上一交付将盲评待答误作自主复验的停止条件，现纠正；用户偏好仍待真实填写。

experiment-1是开发期初步样本，全部失败和修订保留。experiment-2/3采用本目录frozen中相同Skill、brief、fixture以及原共享资产。Skill的设计方法未为首轮分数重写；冻结版包含首轮发现的工程/导出/主题读回修正。三次结果应完整报告，不能把开发期样本冒充与后两次完全同版本，也不能据此无条件证明稳定收益。

每次每组新fork-none子任务，A仅机械helpers和当前业务/强制项目Skill，B另读冻结的新Skill；不读其他组、其他试验的稿件/评分/生成源码。两组相同调用模型与档位，继承宿主；未知细分用量仍null。每组3方向×地图/我的，先实际round0导出回看，至多两轮正式修订，匿名独立评估所有结果。原始实验1的用户比较页保持可用，后续另建比较入口。

Figma复验仍在已授权专用Draft，以唯一experiment-owned根落在y≥13000区域，不覆盖任何历史/手工内容。每次执行读取新鲜URL，源文件不可覆盖重跑；实际PNG+快照落本次round目录，禁止由脚本声明替代导出。
