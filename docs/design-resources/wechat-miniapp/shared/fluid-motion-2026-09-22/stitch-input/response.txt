### Starward 公共组件连续手感与阻尼动效指导 遵从《舒适尺度与自然圆润》及物理阻尼规范，手感扩展以**因果连续性、可预测、单向收敛（无夸张摇摆）**为核心。CSS 仅负责硬件加速变形、安全过渡与进入动量，**不伪造速度计算**，Velocity 判定与实时跟手位移（如图片下拉、横向橡皮筋拖拽、时间尺惯性积分）交由本地共享物理核驱动。 1. **图片查看器（Viewer）**： - 拖动阶段由 JS 实时写入 `transform: translate3d(...) scale(...)`，CSS 在手势释放（`.is-settling` / `.is-dismissing`）时提供阻尼归位或淡出收敛； - 动作支持从任意 Live 状态重入中断，杜绝跳帧。 2. **公共时间尺（Time Ruler）**： - 滑动释放后由物理核计算临界阻尼吸附至刻度并派发唯一 `change`，CSS 仅保持刻度高亮与指针的微动量反馈，严防布局重排。 3. **日/夜/观测三态模式滑块**： - 滑块使用缓动（Apple 风格加减速曲线 `cubic-bezier(0.25, 1, 0.5, 1)`）吸附； - 进入夜光/红光模式时，背景与前景色必须同步切换，严禁在过渡帧出现半透明透白或白色亮底闪烁。 4. **Tab 与按压反馈（.fluid-press / .fluid-tab-label）**： - 点击缩放严格限定在内部渲染层（`transform: scale(...)`），**命中热区与盒模型保持 44–48px 不变**； - Tab 文本选中放大（`scale(1.05)`）使用 `transform-origin: center bottom`，避免引起文字换行或相邻元素抖动。 5. **展开/折叠与名片进入（.fluid-surface-enter）**： - 图层、筛选面板与来源折叠使用单向高阻尼平滑伸展，不附加无意义的反弹动画； - 行程票与观星点名片进场仅施加极轻微的 `Y轴 + 透明度` 抬升，保持仪式感与宁静克制。 --- ### 追加 CSS 代码块（≤ 100 行） ```css /* ========================================================================== Starward · 公共连续手感与阻尼过渡 (CSS 动力学层) 真实 Velocity 计算、橡皮筋阻尼衰减与手势中断由 shared/elastic-sheet JS 核承接 ========================================================================== */ /* 1. 按压收缩与弹性回弹：仅影响内层视觉渲染，不改变外层布局与点击热区 */ .fluid-press { display: block; transform: scale(1); transition: transform 180ms cubic-bezier(0.2, 0.9, 0.4, 1); transform-origin: center center; will-change: transform; } .fluid-press:active, .is-pressed > .fluid-press { transform: scale(0.96); transition-duration: 90ms; } /* 2.
