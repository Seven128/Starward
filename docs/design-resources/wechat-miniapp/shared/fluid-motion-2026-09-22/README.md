# 公共连续动效 · 待审候选

用户授权把合适的阻尼交互扩展到公共组件；本包仍为待审设计资源；2026-09-24 生产 Map 抽屉已接公共弹性核心，原有 `SelectionTabs`、设置模式和时间尺等共享消费者保留各自 owner。候选其余连续交互未宣称已迁移，真机触摸和减少动态效果组合仍待抽查。复用当前舒适尺寸、B 批图标和原交互结构。统一审阅入口：[公共图片](../comfortable-scale-2026-09-22/review.html#motion-gallery)。

| 共享责任 | 当前原型消费者 | 行为与边界 |
| --- | --- | --- |
| 图片直接操控 | 场地照片、停车/洗手间设施相册；点信息作为地图/计划/记录共用组件 | 首尾阻力，横向翻页，下拉缩小与速度关闭，可中断回弹/打开；关闭回当前缩略图，来源失效淡出。图片内容、历史栈与焦点归查看器适配层。 |
| 观测时间尺 | 点位天文、地图云量图层、云观星 | 越界阻力、速度投影到有效刻度；预览随轨道，稳定后一次提交；取消恢复已提交时刻。三者保留自己的时间/数据owner。 |
| 三态模式 | 设置 DAY/NIGHT/OBSERVATION | 拖动或点选，端点阻力、相邻档位吸附；模式语义仍由原设置owner维护。 |
| Tab文字与按压 | 点位章节、创建/反馈章节、创建/反馈记录Tab；当前页面普通按钮 | 选中文字轻放大、反向从当前视觉接管；按压只改变内部内容，44px命中区不动。筛选分类与主导航不并入章节Tab家族。 |
| 面板与展开 | 设置确认、搜索筛选、共享日历/天体详情进入；Sky控件、图层内容、来源与更多场地说明 | 高阻尼连续进入/退出/高度；保留原确认、取消和滚动，不增加拖拽关闭。已有共享事件Modal保留自己的动效owner。 |
| 分享进入 | 行程分享与观星点分享的外壳 | 克制的淡入上移；同一票面/导出PNG不受动效影响；异常/失效态不播放内容进入。 |

公共核心在 core.js；mode.js、image-motion.js、observation-time.js、surfaces.mjs分别维护手势/视图职责。spot-gallery.js接回原相册与导航。当前消费者都引用这些共享文件，不在页面复制物理逻辑；点位抽屉继续引用[elastic-sheet](../elastic-sheet/README.md)，不同手势保留不同边界/锚点。

系统减少动态效果、取消、二次触点与后台处理保留在责任组件。浏览器可编辑原型没有新增运行库依赖；参数和候选行为不构成Taro/RN实现或真机手感验收。生产需接回现有公共组件、原生滚动/返回及观察上下文；不可复制浏览器DOM适配层进入生产。

## 来源及状态

[当前Stitch项目](https://stitch.withgoogle.com/projects/7144519510537620825)已有7张静态总览；本轮只请求公共动效指导，不生成重复静态页面。原始提示与实际返回保存在 stitch-input/。Stitch给出的CSS建议经本地实现适配：保留已采用Tab比例与字体，未采用其另改字号/字重建议。可交互共享实现为本地JavaScript，不宣称Stitch原生组件或静态画布含交互。

研究沿用当前项目已确认的原生手势/弹簧、公共时间尺和图片查看器契约；弹簧只用于连续位置与反馈，不应用于正文、地图科学几何、预警、业务状态或批量列表。不同产品责任不因使用同一物理函数而共享业务状态。
