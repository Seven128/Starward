# WEAPP runtime derivatives

本目录只服务微信小程序发布包。采用源仍是上两级 `assets/` 中的 71 份 256×256 RGBA PNG；现有 `generate.py` 用 Lanczos 等比派生，保留完整透明画布、锚点、颜色、状态和构图，不裁边、不转索引色、不重绘。

普通界面图标输出192×192；地图四态标记、地图/账户图标和行程车的较大用途继续224×224。具体选择由生成器和逐文件manifest拥有。小程序原生TabBar继续使用相邻 `weapp-tabbar/` 的192px专用派生，不受本次改变。母版与采用状态不变，运行时派生不等于新视觉采用。

派生用于遵守微信主包2048KiB限额。原256源曾使实际预览主包达到2088KB；2026-09-28增加已采用想去四分件之前，当前代码主包仅余102bytes，语义修订后超8bytes。按上述用途调整派生并加入四分件后，本地生产检查主包2010203bytes、总4147952bytes。该数字是本次检查观察，后续候选以实际生产检查为准。源图未修改，较大用途保持原像素；本次192px界面图标的实际WEAPP对照及设备限制见当前任务证据，不能从源图哈希推导真机质量通过。

使用工作区随附 Python/Pillow 执行 `generate.py`。`manifest.json` schema2记录每个源与派生的SHA-256、字节数和outputSize；生成过程断言256×256源以及预期尺寸的RGBA输出。夜间/观测模式独立图标尚未由该B资源交付；生产继续遵守各自主题回退责任。

2026-10-09为补回已采用地形图例腾出主包容量，六份现有192px派生由同一生成器在原resize后使用Zopfli重新压缩PNG的DEFLATE字节流。处理工具使用Pillow及zopfli 0.4.3，后者是离线资源加工依赖，不进入小程序或更改项目包管理器。仅IDAT压缩字节及其CRC改变，解压后的完整过滤像素流、所有RGBA像素（含透明区域）、尺寸、非IDAT块和256px母版保持；不转索引色、不降低精度。选定文件和15次压缩迭代由生成器及manifest维护。本次实际节省5830bytes，后续主包仍以完整候选预算检查为准，不据此认证视觉/真机。
