## 当前内容

- 我的新增“个人行程成就”，打开“我的星旅”。用户已确认按结束计划自动统计；样本2份、2地点、1关联天象，与两条记录一致。年份选择、空记录、读取失败、登录恢复状态可审阅。
- 行程分享采用纸质行程票；地点分享采用静态地点名片。点击各记录保留其身份、计划日期与关联天象；计划详情分享只投影公开字段，不带出发地、备注、清单、提醒或账户信息。
- 地点名片只读正式公开摘要。样本星湾有开放/停车/地平线/进入提示；其他样本缺少位置与核验数据时保留缺失状态，不继承星湾资料。
- 两类海报从同一个当前票面渲染PNG，保留对应资料归因；没有伪造可扫码的小程序码。原生微信分享卡片和公共计划分享凭据已进入生产；显式撤销API、小程序码仍属后续生产接入；相册授权后的保存结果与真机返回流程仍待验证，网页下载不是这些能力的证明。
- 分享失效和地点下架状态隐藏内容与可行动操作；缺失/未知身份显示失效，不回退为默认对象。
- `share-shell.mjs` 是原型共用呈现宿主，保持地图抽屉和计划详情的原文档与滚动；关闭恢复原触发点。来源来自现有公共归因 owner；日月食与流星雨分开。所有日期、地点、事实为设计代表数据，不是实地核验或实时观测结果。
