# 本轮验证

使用现有 Browser 插件的 IAB 真实页面，在390×844内容视口检查；截图实际编码可能为390×843，未拉伸补齐。此记录是HTML设计伴随预览证据，不是WEAPP生产验收。

- 真实截图检查有图大档、无图大档、中档、小档和天文章节。照片160px，从平台头部下方开始；无图及小/中档媒体高度为0。
- DOM测量标题18px、搜索文字13px、设施与缺失值12px；导航32×32、箭头14px；两个设施卡片各358×52、上下8px间隔。中档候选368px，小档156px；固定操作各40px可见高度并有44px扩展命中区。
- 点击收藏后pressed为true，恰好2个副星、3条拖尾；读到旋转过程中的非终点矩阵；取消后读到反向过程，随后再次激活回到scale0.92的终态。没有用工具无法提供的动画队列API作为通过证据；节点保持/无重建由源代码检查支持。
- 键盘从大档收回中档，过程读到媒体仍完整、搜索已开始恢复，终态媒体归零；实际鼠标拖动把手可到小档。小档保留唯一文档和3个固定按钮，内部滚动关闭。
- 从小/中激活天文，先展开大档，再定位同一文档，焦点落在天文区域。修复短章节无法足够滚动及当前章节错判；复查天文顶部147.2px、导航底124.8px，当前章节为天文。
- 反馈纠错按钮可操作，打开明确的预览跳转说明，返回恢复页面；不伪造正式投稿。
- 图片均本地加载且naturalWidth非零；源文件检查未引入远程字体、图标和运行依赖。
- Context manifest/path检查与git diff空白检查通过；这些检查不证明产品事实正确。

尚未实测：用户本轮手机观感、真实WEAPP、字体放大/读屏、系统reduced motion运行、夜间/观测主题、媒体版权与真实数据长文、真实服务错误/回滚、地图和滚动竞争。reduced motion已写CSS但不标作设备验证通过。静态图中普通文字的浅色对比沿用既有待协调项。
