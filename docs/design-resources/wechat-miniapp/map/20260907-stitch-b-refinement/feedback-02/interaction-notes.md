# 交互与迁移说明

## 三档与媒体

三档保留同一份 DOM 文档，顺序为适用媒体、身份、基本信息/天文章节导航、基本信息、天文；操作区独立固定。小、中仅裁剪，大档内部滚动。只有把手 96×44 的区域触发换档，轻点不换档；方向键/Home/End提供键盘替代。章节操作从小/中展开大档后在同一滚动区域定位并更新当前章节与焦点。

有图时中档及以下占用零媒体高度；向大档展开时照片高度和透明度连续增加，接近大档才淡出搜索与地图控件；反向先恢复控件，再收起照片。媒体先于身份；无图不使用占位、替代风景或虚构版权。预览只展示一张生成示意图，未模拟多张排序、媒体加载/失败/过期、真实摄影署名和授权来源排版。

预览采用可中断的300ms面板插值及简化的位置/速度选档，不代表现有WEAPP协调器、边缘返回、滚动竞争和设备手感已验证。生产复用现有协调器，不复制这份网页手势脚本作为新架构。夜间/观测模式和真实系统安全区继续遵循当前 owner。

## 想去

用户确定：圆角五角主星；激活多圈翻滚并稍微缩小，出现恰好两颗更小的星星，三者都有黄到绿的渐变拖尾。主星始终最大。取消反向同圈数，副星和拖尾淡出并恢复描边。活动态不循环或自主闪烁，标签始终为“想去”。

本轮候选参数：主星20px、两颗副星7px/6px，旋转720°、760ms、缩放0.92；副星渐显280ms。第二次点击直接改变同一节点的目标，接管当前视觉值，不重建节点、不强制重排、不排队。快速中途反转只回退已走过的角度；完整选中后取消才反转完整两圈。

此处只模拟本地选中关系。生产仍需提交同一favorite关系，处理中/失败回滚/相邻恢复、Map与Search一致性、身份切换及权限语义。辅助功能必须同步pressed/busy状态；reduced motion无旋转和副星位移。观测模式三颗星及拖尾全部使用既有暖红封闭色域；本轮只画日间。

## 事实与动作

来源句使用实际provider/contributor及核验日期，同源可以共享，异源要分别追溯；当前缺失样例只显示“资料来源：暂无数据”。地图署名不代表场地来源。

“更多场地信息”对应现有 `/spot/field/index`，只在摘要之外确有资料时出现；本缺失样例不放空入口。攻略、其他设施、海拔等按有效字段出现，其职责见核对表，不因本图未画而删除。

反馈纠错沿用 `/content/contribution/index` 并带正式点位身份；本预览按钮只打开明确标记的目标说明，不模拟投稿、待审核成功或新反馈页面。导航保持32px视觉按钮/44px命中区、14px居中右上箭头；生产复用合法进入/关闭/显式危险核对和真实坐标交接。云观星仍校验正式点与Observation Context。外部地图、分享、账号、定位、图层及云观星业务没有连接。
