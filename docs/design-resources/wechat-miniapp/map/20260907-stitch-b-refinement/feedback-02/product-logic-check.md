# 本轮产品逻辑核对

范围：地图观星点信息组件及其依赖入口。依据是当前 Screen Contract 与数据类型；源码仅用于判断实现差距，不反向缩减产品要求。此表是本轮核对记录，不复制成共享 Skill 的固定产品清单。

## 信息职责与去向

| 责任 | 当前事实源 | 设计表达与条件 |
| --- | --- | --- |
| 名称、区域、地址、海拔与相关场地特征 | `SpotSummary` | 身份始终可辨认；地址和有意义的地形/通达事实按有效数据呈现。不能因一张无数据图就从产品里删除 |
| 路线估计/直线距离/不可用 | `RouteOverview.kind` | 路线行明确区别，不把直线距离称作驾车路线；没有定位权限不捏造起点或行程 |
| 步行、末段道路、停车指引 | `RouteOverview` | 相关说明留在路线/停车对象附近，长说明自然展开；详情入口不能替代必要的到达限制 |
| 开放时段 | `FacilityEvidence.openingHours`及正式证据 | 普通文字行；不混为开放状态。不同设施时段分别关联对象 |
| 停车、洗手间 | `FacilityEvidence` | 两张上下独占整行卡片；状态、距离、条件、说明和核验信息按真实字段出现 |
| 观测平台、充电、露营、道路、徒步、通信 | `FacilityType` | 有实际资料时紧凑呈现，不强制六个空卡；完整说明可进入更多场地信息 |
| 开放状态、合法进入、夜间安全、显式危险、限制与指引 | `AccessAndSafetyState` | 当前基本信息层可读；严重阻断紧邻受影响动作，不能只藏到详情；未知不等于安全/允许 |
| 场地证据、冲突和失效 | `FactEvidence` | 不把用户报告自动视为已确认；与受影响事实关联，详情可追溯 |
| 有效场地媒体与版权 | `RepresentativeMedia`、`siteMediaState` | 顶部媒体先于身份，仅向大档拉出；无图/非法/过期不造占位。署名、授权、是否场地专属均需保留 |
| 攻略 | `GuideArticle` | 实际存在时显示摘要、作者与文章入口；没有时不造攻略标题卡，不替代安全事实 |
| 资料来源与核验 | `SourceSummary`、每项 verifiedAt | 可读信息行；同源可共享，异源分别追溯。地图署名不代表设施/天气来源，来源缺失不捏造提供方 |
| 反馈纠错 | Map 的 `onPanelContribution` | 有名按钮，进入现有 `/content/contribution/index`，携带正式spotId/spotName；身份和草稿隔离、提交待审核规则不变 |
| 更多场地信息 | `onPanelEvidence("field")` → `/spot/field/index` | 原“场地资料”的完整设施/道路/安全证据页；确有更多内容才显示，返回同一地图和上下文 |
| 完整来源 | `onPanelEvidence("sources")` → `/spot/data-source/index` | 需要更深入追溯时明确进入来源详情，不把source摘要做无效链接 |
| 天文事实 | `spot-and-sky.md`、panelAstronomyFacts | 基本信息后的同一文档；真实时间片/气象/光污染/月相/目标及来源，0与缺失区分，不补假星图/推荐窗口 |

数据类型：`packages/miniapp-contracts/src/types.ts`。代码核对：`apps/wechat-miniapp/src/pages/map/spot-panel.tsx`、`pages/map/index.tsx`、`features/spot/spot-detail-page.tsx`。

## 状态与互动

- small/medium/large保留同一文档；只有large内部滚动；固定三个操作与Map/My不被遮挡。小/中裁剪不是删除数据。仅把手区可以开始换档，轻点无效；章节激活先展开large再定位，返回保留正式点位与上下文。
- 媒体高度和透明度随展开进度变化，地图chrome在接近全屏时才退场；反向先恢复chrome再收媒体。原Context曾同时存在相反的反向顺序，本轮统一为DESIGN的同一顺序。
- 导航先通过真实安全/合法进入/可用上下文检查再交给地图提供方；图标方向不是新的导航数据。Cloud action继续验证正式spot和Observation Context。
- 收藏保持同一favorite关系；成功不额外toast，失败回权威值，快速反转接管当前角度/缩放/透明度。新规则是主星加恰好两颗副星；本轮2圈/760ms/.92是演示参数，用户尚未确认精确时长。
- 来源行不伪装按钮；纠错是明确按钮。预览里的跳转只表达控件和目标职责，不假装已连接真实投稿后端。
- 模式、reduced motion、授权失败、加载/旧值/错误、长文本/真实数据、有图片与无图分别保留职责；没有被本次静态输出覆盖的状态不能声称已验收。

## 已发现的缺漏与迁移边界

上一轮无数据截面漏画基本信息的访问限制/安全等职责，并用三个无效浅色链接代替来源与动作，也没有有图示例；这不代表产品原本只有三个设施字段。本轮修正资源与Context，生产仍待迁移。

当前面板实现已有路线、设施、开放/夜间安全、攻略与来源入口；完整场地页也承载合法进入等证据。新设计必须补足基本信息层对合法进入、显式危险和限制的可读性，不能因为现有面板未完整呈现就改写要求。实际场地/天气信息及生产错误状态仍需数据与WEAPP验证；资源生成不证明这些行为正确。
