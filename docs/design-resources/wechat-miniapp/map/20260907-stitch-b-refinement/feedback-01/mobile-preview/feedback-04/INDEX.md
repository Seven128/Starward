## 本轮设计取舍

沉静绿负责功能与选中，暖黄集中于想去/流星，正文深中性、白色画布，事实分组使用同一种极浅绿。Stitch 原稿使用深林绿 #1B4332、浅底 #F2F7F4、黄 #E5A93C；交互修订更柔和，候选主绿 #38634C、浅底 #F0F5EE、云观星 #3E554A，保留原已确认流星黄绿。精确参数位于 refinement.css，尚待采用，生产 tokens 尚未迁移。

同组一个线性 icon + 组名，组内平铺数值；云层四列，温湿和风/能见度三列，降水两列，月亮/夜间三列。卫星夜光和目标保留独立语义。模型一致性与更新来源一起显示。统一底色、不套小卡、不加各类不同颜色。

Stitch 原稿擅加微风宜行、凝露风险较低、暗空质量优、模型折算透明度等内容，且有标签挤压、套卡、时间尺容器及产品内调试标签；它们均未进入交互修订。不得把原稿生成文案视为产品或数据依据。

## 图片动效

照片从所点设施卡片的实际视口矩形和裁切出发，连续扩展为清晰完整图片，遮罩/模糊同步淡出；反向关闭回到同卡片。预览候选全程360ms，反向从当前进度接管。两种照片各用自己的原图和比例，保持文档滚动、档位、焦点；解码期间关闭会取消后续展开。系统减少动态效果时只短淡入淡出、不放大。生产使用平台适当能力落实同一交互，不照抄浏览器 dialog API。
