## 生成来源

按项目默认路线向Stitch提交原提示词，两次均返回“发生了意外错误，Stitch无法完成生成作业”。未出现所请求的两张画板，实际新Stitch屏幕数0，用量未知。`run.json`与`stitch-error.txt`保留记录，没有把Codex改稿冒充Stitch输出。

[Stitch路线规则](../../../../../../.agents/skills/starward-design-resource/references/stitch-route.md)要求：“一次重试仍失败就停止生成并说明”。因此本轮不继续重试生成服务，改为在既有可编辑源稿中完成用户明确要求的局部变化，保留所有原稿。

## 数据与照片边界

“星湾观星点”、设施状态、路线、日期、时间片、天体方向和数值全是用户授权的设计示意数据，不是实际地点/实时预报，也不代表天文学计算正确。`full`只代表本轮可用字段较完整；独立透明度/视宁度及结构化升落事件缺口仍诚实保留。数据情景在画面外切换，生产禁止用它们填补缺失。

设施参考照片：停车由Matthew Paul Argall拍摄；洗手间为Benjamin Berne / SuSanA Secretariat的北京奥林匹克森林公园照片。两者均按Commons描述页的CC BY2.0许可使用，原文件未改；卡片只是CSS裁切、轻虚化及浅色遮罩，大图无该滤镜。评审页和大图内保留作者、来源和许可链接。它们不属于虚构观星点，生产不得直接当现场媒体。总览图沿用上轮Stitch生成示意素材。

## 本轮产品规则变更

Context已区分无记录、已有记录部分缺失及请求失败；最小采集改为结构化核心资料，核心证据核验后公开、可选资料逐步补齐；电话允许无/未知；设施媒体需要明确关联；天文按实际输出语义分组。生产代码仍使用旧投稿字段、严格发布评估与缺少设施媒体关联的类型，需要后续迁移。本轮没有改实际记录、发布状态、数据库或生产页面。
