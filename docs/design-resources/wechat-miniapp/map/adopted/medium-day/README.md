## 采用范围

用户确认原 B 的精致尺度：36px 胶囊搜索框、36px 白色圆形细线工具、18px 地点名、13px 章节/路线/底部动作、12px 设施与缺失状态。路线为平铺行，右侧导航仅一个方向箭头；底部三项独立按钮保持「想去 / 分享 / 云观星」，主导航为横向图标与文字。精确页面视觉值及与旧规则的优先关系见根 DESIGN.md 的「5A.0 已采用地图日间中档表达」。

范围只覆盖无场地媒体、普通缺失值的日间中档首屏。三个底部操作在实现中仍属于独立 action owner；HTML 把它们写在 main 内不改变三档共同操作区的责任。概览/天文仍定位同一连续文档，不能照搬静态 HTML 成为两个内容树。业务状态、风险、来源、手势、授权与数据仍由 Screen Contract 决定。

## 实现边界

原始390×844构图为尺寸比较基准；其他屏宽保持已确认字级和可见控件尺寸，以容器宽度/实际安全区适配，不能把整张截图缩放当作实现。设备系统栏和微信胶囊由平台布局映射，不复制示意系统图形。

`map-reference.jpg` 来自采用源稿同一 Stitch 地图素材URL，保留 © OpenStreetMap 贡献者署名；只作背景参考，不是生产地图资产或可靠投影数据。示意点标落在海面的问题未解决，生产必须以正式点位坐标和真实地图 owner 为准。底图/provider 外观不属于 app-owned 像素还原范围。

浅灰辅助文字的颜色对比度仍待与共享无障碍颜色规范协调；本次视觉采用不等于通过4.5:1检查，也不授权删除缺失信息、放大字号或擅自重排来规避。开发需要显式呈现必要的颜色修正供核对，不能默默近似。其余平台字体差异、真实连续手势与WEAPP效果亦未验证。

图标只有可见轮廓，实际动作必须保留程序化名称、状态、焦点与完整命中区。不要复制静态 HTML 中尚未实现的动作或其全局 select-none/overflow-hidden 到真实可滚动文档。
