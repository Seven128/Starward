# 云观星 · 正式采用

## 来源与复用
Stitch首次生成A/B，后续一次局部修订。raw/screen-1.html为初始B、screen-2.html为初始A，来自Stitch画布iframe的原始srcdoc，包含其运行样式/脚本，未冒充独立官方导出包。原稿的天体位置/日期/星座线仅是设计示意，不能作为天文事实。交互版本地修正标签换行、异常形状、重复时间，替换静态星场。

公共日期时间来自shared/observation-time，未复制手势实现；相机几何由build-sky.mjs转译现有sky-view-projection.ts；真实Gaia星表先经既有完整性校验与现有投影生成50个固定切片。保留亮度和色指数，不增加随机星点或图像星云。织女星输入取现有gaia-catalog.test.ts的天体测量fixture（不冒充Gaia星表记录）；月亮和土星由已安装的Astronomy Engine计算。示例坐标22.6,114.5、海拔30m，不是正式观星点。build-sky.mjs通过node --import tsx重新构建，不依赖海外接口或新增库。

## 交互与范围
画外的织女星/土星视野仅注入演示姿态，页面没有手动拖动天空或方向开关。真传感器只经启用动作申请；无绝对方向/无样本不宣称跟随，后台/离开停止监听，过期暂停。未建立WEAPP方向校准或真机精度结论。时间滑动更新对应切片；跨午夜日期联动；可见天体采用理论地平线，不宣称排除山体/天气遮挡。页面不调相机。
