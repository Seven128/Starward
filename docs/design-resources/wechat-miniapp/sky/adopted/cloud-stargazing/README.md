# 云观星 · 正式采用

[交互预览](review.html) · [Stitch原稿](raw-review.html) · [Stitch项目](https://stitch.withgoogle.com/projects/13823253487989500123)。状态：2026-09-09用户确认采用。默认A轻标签；B保留焦点卡参考，不新增产品模式设置。A是轻标签，B是天体焦点卡，两者共用天空/时间实现。

## 来源与复用
Stitch首次生成A/B，后续一次局部修订。raw/screen-1.html为初始B、screen-2.html为初始A，来自Stitch画布iframe的原始srcdoc，包含其运行样式/脚本，未冒充独立官方导出包。原稿的天体位置/日期/星座线仅是设计示意，不能作为天文事实。交互版本地修正标签换行、异常形状、重复时间，替换静态星场。

公共日期时间来自shared/observation-time，未复制手势实现；相机几何由build-sky.mjs转译现有sky-view-projection.ts。浏览器预览保留当时的固定切片和示例坐标，只用于构图；当前生产目录改由完整性绑定的BSC5P亮星包、OpenNGC 51目标和Astronomy Engine结果组成，不生成随机星点。深空影像使用本地发布的`allwise-w3-messier.v20260501`，每个目标3级、AllWISE W3 12µm、北上东左，运行时不请求境外影像服务。

## 交互与范围
2026-09-16会话校准采用用户实测后的冻结交互，替代滑块调整。跟随状态提供“重新校准”；进入后固定当前完整星图，用户移动手机对准现实参照，点击“确定”后画面保持连续并继续跟随。“取消”恢复此前校准关系下的当前手机方向。校准后本来就在跟随，不增加“恢复自动”入口；用户需要再对齐时重新进入校准。

| 状态 | 用户看到与可执行的动作 | 保持的责任 |
| --- | --- | --- |
| 有新鲜姿态的跟随 | 重新校准；可切换拖动模式 | 地点、时刻、完整视角由现有 owner 维护 |
| 正在校准 | 固定星图；取消/确定，提示移动手机对准图中方向 | 继续采集姿态，暂停时间、日期、拖动、缩放与天体点选，避免参照变化 |
| 确定 | 不跳变，随后新姿态继续带动画面 | 用确认时最新姿态建立完整旋转关系，包含俯仰与侧倾 |
| 取消 | 恢复此前关系下的当前方向 | 不提交这次调整，不清除此前有效校准 |
| 断流、过期或后台返回 | 保留画面，按状态提供重新连接/重新校准 | 不沿用已失效的原生参照；新鲜姿态回来前不能确定 |

此表是用户已确认的交互范围与状态说明，不是新视觉稿。当前 HTML 预览尚未演示上述校准控件，旧预览的传感器公式、恢复措辞和固定样本不得作为生产算法或数据依据；生产完整状态由 Screen Contract 和 direction-alignment/sky-orientation-controller 维护。现有天体信息卡和公共日期时间等采用区域仍有效。校准控件的实际整页构图和目标设备验证继续单列。

2026-09-15用户补充采用拖动模式。生产页面在同一相机owner中提供手动视角与手机方向跟随：单指旋转、双指缩放；显式按钮可进入手动视角或请求恢复跟随。手动basis与设备pose分开，无绝对方向/无可信样本时继续允许手动浏览，但明确“不代表手机朝向”；后台/离开停止监听，过期暂停，恢复跟随必须取得新可信pose。屏边保留系统返回手势，tap、drag、pinch和cancel不得互相误触发。时间滑动、跨午夜、对象选择和深空分级影像共用同一地点/时刻/相机身份；观测红光模式隐藏处理后影像。可见天体仍是理论投影，不宣称排除山体或天气遮挡。
