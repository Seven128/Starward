# 云观星：放大后可读真实星系影像

2026-09-09 用户明确要逐级显示更清晰的星系/星云影像，不是星点或低清图片的纯放大。本轮仅调研与产品/架构描述，不开发生产功能。

## 当前事实

`apps/wechat-miniapp/src/features/sky/spot-sky-page.tsx` 的 `SKY_VERTICAL_FOV_DEG = 45` 固定；其星点和目标投影复用 `sky-view-projection.ts`，未发现天空缩放状态或双指缩放处理。候选 `sky/.../preview/app.mjs` 同样固定45°，输入为星表与少量目标，没有真实深空影像图层。既有时间尺触摸不是天空缩放。

## 本轮实际浏览验证

打开[Aladin Lite官方示例](https://aladin.cds.unistra.fr/AladinLite/)，目标输入M31，已看到DSS colored仙女座星系影像，并通过滚动放大：可见视野从约1.785°×56.37′缩至约15.66′×8.237′。看到了星系结构及更近的影像；核心区域亮部饱和，证明数据自身也有可读性限制，不能承诺放大后处处更漂亮。此为本机Chrome官方Web示例的功能观察，未测瓦片请求量、帧预算、小程序兼容或国内部署可达性，也不是项目嵌入完成。

## 产品与架构约束

- 影像来自历史巡天/望远镜观测，可能经过多波段合成与亮度拉伸。必须保留来源与波段/处理说明入口，不当作当前肉眼天空、天气或手机相机直播。
- 统一天球坐标与视窗投影；恒星、行星与影像不能各自移动。不同参考系/历元的转换、足迹与方向需有证据，不能仅用天体名字贴一张图。
- 远景先用低分辨率，缩小时降级、放大时按足迹与屏幕需求加载高层级；旧层保持到新瓦片齐备，失败保留已有层并局部说明。限定并发、缓存纹理/内存；取消过期请求。不能每帧随传感器变化重下瓦片，也不整包全空域影像。
- 最大放大由影像原始分辨率、显示尺寸及姿态稳定性约束；先前提交Stitch的1—3×控件只是已撤回上限假设的视觉探索，未集成，也不写成最终上限。高倍率放大姿态噪声，锁定/暂停跟随的必要性与返回规则需进一步验证，不默默增加手动方向模式。
- 数据源授权与引擎许可证分开。DSS并非无条件公有领域：[MAST Data Use](https://archive.stsci.edu/publishing/data-use)区分版权数据的非营利使用与商业许可；[DSS数据说明](https://outerspace.stsci.edu/spaces/MASTDATA/pages/176435492/Photographic%2BSky%2BSurveys)不允许无协议批量再分发。个人非商业试用也不自动授权全量镜像。来源页与署名需保留；具体源/版本的缓存与托管边界在实施前逐项核对。
- 小程序接入不是浏览器嵌入的直接同义词：检查DOM依赖、WASM加载、WebGL版本、域名白名单、图片跨域、纹理上限、前后台恢复及账户可用的载体能力。微信官方canvas/web-view文档本次读取失败，不能据此认定支持或不支持；当前未验证原生WEAPP或web-view方案。
- 月预算350元不变；以实际会话瓦片数×平均bytes×会话量估算CDN流量/请求与缓存成本，再对照真实报价。公开免费源不等于有可用性承诺。本轮没有付费、镜像下载、部署或修改生产数据。

## 后续验证应解决的问题

用M31（星系）、M42（星云）及无影像区域检查多级清晰度、足迹/星点配准、边界和降级；在真实目标WEAPP设备验证内存、帧时间、手势冲突、姿态抖动、上下限、弱网、失效重试、前后台和红光。先据此选载体/引擎/数据源与上限，再用design-resource精修真正可实现的交互。此项技术验证未在本轮冒充完成，也不阻塞其他四组设计审查。
