## 已确认设计与交互

- Map与Search复用同一框、同一input/query。原型的框为36px可见高度、左右16px、13px文字；顶部位置按采用地图入口和实际平台安全区映射。框不移动、不变形，只有Search/Back图标在原槽交叉淡化，下方页面拉出/收回。
- 18个既有筛选值只占一行横滑，右侧漏斗固定；每项有独立44px目标。全部筛选用两级「类别→终端值」：观测条件、到达方式、设施配套、场地偏好、资料更新。横排即时提交；弹层从当前选择复制draft，清空改draft、确定提交、关闭/遮罩/Escape取消，回到同一committed状态。
- 「想去」「其他观星点」两分区均可展开收起，保留同一内容树，可在运动中反向。分组头和数量紧凑，实际目标不少于44px。
- 有图结果卡无边框/阴影，图片覆盖整卡、左侧文字可读渐隐；无图使用轻表面且无占位。地点名与地址保持紧凑层级，地址图标槽与首行同高，长文本自然换行。
- 整卡的真实产品动作是：提交正式点→退出Search→原Map居中该点→打开该点medium信息组件；重复选同一点也应重开medium。本包只展示卡片按压，静态Map截图不证明这条链路。
