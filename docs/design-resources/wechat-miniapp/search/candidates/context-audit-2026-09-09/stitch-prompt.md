本次产品已确认变化：删去“今晚推荐”和“最佳窗口时长”，共16项。“摄影前景”改为“有实拍照片”。五类：观测条件=光害、少云、特定天象、低云阈值、月亮影响、天空开阔方向；到达方式=驾车时长、可驾车直达、徒步难度；设施配套=停车、厕所、信号、充电；场地偏好=有实拍照片、可露营/驻车；资料更新=最近核验时间。

本张展示到达方式分类选中。右侧紧凑驾车时长配置区：清楚可选择启用的“驾车时长”项、启用后同层数字输入“180 分钟以内”（范围30—360整数，提示只在错误时出现）、下面两项“可驾车直达”“徒步难度”。不新增第三层分类、独立设置页或重复卡片标题。应明显比普通无参数项多一个可编辑值，但仍小巧精致，键盘出现不会挡住当前输入与操作。背景横滑栏显示已提交的“驾车180分钟内”“少云”等，没有旧推荐项。

操作：点击横滑驾车项进入这同一个sheet；打开复制已提交选择和时长，内部选择/数字/清空仅改草稿；清空禁用并重置默认180；确定验证30—360整数后提交；关闭/遮罩/返回取消所有草稿变化。其他无参数胶囊依旧即时选择。关闭sheet后仍是同一搜索页，分组和滚动不重置。

实际筛选判断是服务端未来工作，不在设计中伪造真实API。在画外可切换正常、部分覆盖、低云缺失、真实零匹配演示：部分覆盖用搜索结果附近一句“少云：3个地点中2个可判断”，不可用显示“低云数据暂不可用”并可移除/重试；真实零匹配显示没有符合当前条件的地点，不混成加载失败。瞬时天气筛选依据当前选定时刻，无需常驻技术解释。画板外才放审阅说明/示例状态，画内不出现工程、版本、fixture字样。为本轮新增参数和局部状态设计，其他已采用区域尽量不动。
