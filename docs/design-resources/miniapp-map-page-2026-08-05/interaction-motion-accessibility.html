03 · Explicit flows

搜索、筛选/图层、位置、路线、详情与模式

每条流程都包含取消/恢复路径；只引用地图页和外部交接边界，不新增产品页面。

搜索

1
Open触发器打开 dialog；焦点进入返回/输入。
2
Query草稿持续保存；loading 保持稳定结果容器。
3
Choosespot 同步点位；ordinary place 只移动地图并提供“查看此处夜空”。
4
No result / degraded区分真实无结果与 provider 降级/缓存不完整。
5
CloseEscape/返回关闭，焦点回搜索触发器。

清空后焦点留在输入框；普通地点不会自动成为正式点位。

筛选 / 图层 Sheet

1
Open 220msSheet 从底部进入；handle 可见时才响应 drag。
2
Edit选择计数实时更新；大字自然换行，内容可滚动。
3
Apply提交并保留到详情返回和模式切换。
4
Reset / cancel重置是显式动作；取消不提交暂存值。
5
Layer failure退回标准地图，保留点位级估算、来源与时间。

一次仅显示标准地图 + 一层有界业务辅助叠层。

位置权限

1
Usable first frame先显示 Demo 试行区域；不自动弹系统授权。
2

不默认持续定位；精确用户坐标不进入普通遥测或候选内容。

系统大字 / 屏幕阅读器等价语义

标题、结论、来源、更新时间和恢复动作不限单行；卡片可独立滚动，主要 CTA 保持可达。读出：“驾车距离 28 公里；预计用时 45 分钟；位置精度，区域级。”

07 · Lifecycle & resource posture

实现审阅者可见的资源规则

这些是可见设计约束，不是 `<3s`、设备性能或真实服务通过的声明。

Pan-end

地图移动期间不每帧请求或显示 spinner；结束后约 200–350ms debounce。

bbox + zoom + date + filters + layerVersion
Cancel previous

新 viewport 请求取消前一个；旧响应不得覆盖新中心或选点。

latest request owns commit
Preserve cache

缓存地图立即恢复；PARTIAL/STALE/OFFLINE 保留静态与最后仍有效事实。

missing ≠ zero
No pan spinner

只在首次/明确重载展示稳定骨架；背景刷新不移动控件。

stable geometry
Cleanup on exit

离开页取消请求、定时器和监听；保存任务状态；不复制 spot truth。

one state owner per fact
隐私与边界：无连续定位默认；精确用户坐标不进入普通遥测；受限坐标不发送外部目标；外部导航先确认目的地。真实地图、授权、生命周期、安全区、haptic 能力、可访问 API 和性能都仍需微信真机验证。
