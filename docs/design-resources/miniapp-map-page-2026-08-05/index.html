设计说明
  • 层级：搜索与筛选 → 地图证据 → 选点摘要 → 全局导航。
  • 不变量：模式、图层与弹层切换均保留中心、筛选和当前选点。
  • 状态：缺失不作零值；过期不再标为推荐；失败保留静态事实。
  • 边界：路线只给概览，外部地图接管导航；观测红模式先行警告。
  • 验证：真实地图、授权、生命周期、安全区和性能仍需微信真机确认。

演示地图为内联矢量模拟，不含真实瓦片、坐标、图片或服务调用。候选未构成 Product Surface 采纳。
